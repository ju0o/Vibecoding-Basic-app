BASIC 05 · REBUILD DIRECTION

5강은 “배포 도구 소개”가 아니라
내 프로젝트가 공개 서비스가 되는 한 번의 여정으로 다시 만듭니다.

지금의 문제는 요소를 조금 추가한 것이 아니라, 실제 화면과 핵심 장면이 한 이야기로 연결되지 않았다는 점입니다. 그래서 카드와 생성형 이미지를 줄이고, 실제 브라우저·GitHub·개발자도구·배포 콘솔을 중심으로 재조립합니다.

01

내 컴퓨터

localhost는 왜 나만 볼 수 있는가.
실제 서비스 화면으로 시작합니다.

02

기록과 협업

Git commit · GitHub push · clone이 실제 화면과 로그로 이어집니다.

03

공개 전 보안

F12 Network · 환경변수 · Firestore 규칙을 한 번의 위험/복구 흐름으로 보여줍니다.

04

실제 공개

Vercel 또는 Firebase를 선택하고, 배포 로그와 공개 URL까지 확인합니다.

유지할 것

발표자 수동 진행, 명령어 실습, 프로젝트 공개 전 점검, 30분 타이머와 다음 강의 예고.

걷어낼 것

의미 없는 카드 전환, 잘린 캡처, 화면 없이 텍스트로만 설명하는 슬라이드, 기능이 보이지 않는 “흐름 보기” 버튼.

권장: 5강을 “실제 화면 1개 + 강사가 누르는 변화 1개 + 한 문장 결론” 구조로 재편합니다. 이 방향으로 바로 재구성해도 될까요?
