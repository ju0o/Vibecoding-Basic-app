좋은 수정 요청의 네 단계

찾기관련된 파일과 연결 관계를 먼저 찾아줘.
설명각 파일을 왜 수정해야 하는지 초보자에게 설명해줘.
수정필요한 파일만 최소 범위로 수정해줘.
검증변경 파일과 브라우저 확인 방법을 정리해줘.

AI IDE에 전달할 예시

예약 화면의 버튼 문구와 색상을 수정하려고 합니다. 먼저 관련된 페이지, 컴포넌트, 스타일 파일을 찾아 각 파일의 역할과 연결 관계를 설명해주세요. 그다음 필요한 파일만 수정하고, 마지막에 변경된 파일 목록과 브라우저에서 확인할 항목을 정리해주세요.
핵심: 찾기 → 설명 → 수정 → 검증
COMMON MISTAKES

초보자가 가장 자주 겪는 파일 구조 실수 3가지

14
1

상대 경로 표기 에러

점(.)의 개수로 폴더 깊이를 세는 상대 경로 표기 오류입니다.

Bad C:/my-app/src/components/Btn
Good ../../components/Btn
2

대소문자 파일명 불일치

로컬 PC(Windows/Mac)와 배포 서버(Linux)의 대소문자 구분 차이입니다.

Bad import button from "./Button";
Good import Button from "./Button";
3

정적 자원(Assets) 경로 유실

이미지나 로고 파일을 호출할 때 최적화 폴더 경로가 꼬이는 문제입니다.

Bad src/assets/images/logo.png
Good public/logo.png → /logo.png
