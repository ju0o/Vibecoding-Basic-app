MCP OR NOT

MCP가 답인 경우와 아닌 경우를 구분합니다

MCP가 답인 경우

AI가 외부 시스템에 직접 접근해야 할 때 — 실시간 데이터, 실제 브라우저 확인, 사내 문서.

복사·붙여넣기가 반복되고 있다면 연결할 때입니다.

MCP가 답이 아닌 경우

한 번뿐인 정보는 그냥 붙여넣는 것이 빠릅니다.

문제가 “절차의 반복”이라면 연결이 아니라 Skill의 일입니다.

연결부터 늘리면 관리 대상만 늘어납니다. 반복되는 접근이 확인된 곳에만 답니다.

MCP SECURITY

연결을 늘릴 때는 권한 최소화 3원칙을 지킵니다

  • 처음에는 읽기 전용으로 연결하고, 쓰기 권한은 필요해질 때 연다
  • 전체 드라이브가 아니라 필요한 폴더 · 테이블만 연결한다
  • 처음 보는 MCP 서버는 만든 곳과 권한 범위를 확인한 뒤에 설치한다

연결은 능력이자 공격 표면입니다. 편의보다 경계를 먼저 정합니다.

SKILL VS PROMPT

긴 프롬프트를 잘 쓰는 것과 Skill로 저장하는 것은 다릅니다

매번 긴 프롬프트

나 혼자의 요령이 팀의 자산이 됩니다.

프롬프트는 소비되고 사라지지만, Skill은 쌓입니다.

SKILL FAILURE

Skill은 편해질수록 오작동도 커집니다. 언제 쓰지 않는지까지 설계합니다.

SELF CHECK
