연결할 때 읽기/쓰기 범위를 좁게 잡고, 민감한 작업은 승인을 거치게 합니다.

PARALLEL · SUBAGENT

SubAgent — 큰 작업을 나눠서 병렬로

큰 작업로그인 기능
서브 AUI
서브 BAPI
서브 C테스트
리뷰 후 통합 ✓

한 작업을 겹치지 않는 단위로 나눠 동시에 진행하고, 검증한 것만 합칩니다.

ISOLATE · WORKTREE

Worktree — 격리된 작업 공간으로 충돌 방지

main안정 버전
worktree-1 · 기능 A
worktree-2 · 기능 B

각 작업을 분리된 공간에서 진행하면, 동시에 여러 기능을 만들어도 서로 안 섞입니다.

AUTOMATE · WORKFLOW

Workflow — 반복 흐름을 자동화

트리거PR 생성
검토diff 분석
테스트자동 실행
리포트요약 게시

매번 손으로 하던 정해진 단계를 트리거 한 번으로 자동 실행합니다.

EXAMPLE · WORKFLOW

Workflow 예시 — PR 자동 리뷰

workflow — pr-review
# PR이 열리면 자동 실행› 변경 파일 수집› 위험 지점 표시✓ 리뷰 요약 코멘트 게시✓ 사람은 판단만

사람은 판단·승인에 집중하고, 반복 수집·정리는 Workflow가 대신합니다.
