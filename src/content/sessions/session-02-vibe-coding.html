AI IDE TOOLS

AI 코딩환경 — 네 가지를 알아봅니다.

C
Cursor
입문 추천
자연어로 만들고 싶은 기능을 설명하면 코드베이스를 읽고 파일을 수정하는 AI 코드 에디터입니다. 처음 실습하기에 자료와 예제가 많습니다.
K
Kiro
Spec 중심
요구사항을 먼저 정리하고, 명세와 작업 목록으로 쪼갠 뒤 구현하는 방식에 강합니다. 막연한 아이디어를 구조화할 때 좋습니다.
W
Windsurf
Cascade Agent
Cascade가 파일, 터미널, 브라우저 흐름을 함께 보며 작업합니다. 여러 파일을 오가며 고치는 프로젝트형 실습에 어울립니다.
A
Antigravity
Agent-first
Google의 에이전트형 개발 플랫폼입니다. 에디터, 터미널, 브라우저를 넘나들며 작업 계획과 검증 결과를 함께 보여주는 방향입니다.

오늘은 Cursor · Kiro · Windsurf 중 하나로 시작하고, Antigravity는 에이전트형 IDE 예시로 함께 봅니다.

FLOW 01-03 · 오늘의 실제 흐름

흐름 01
말
막연하게 말하기
아이디어가 흐릿해도 괜찮습니다. 목적, 대상, 분위기만 말해도 AI가 되묻습니다.
나: "취업용 포트폴리오 같은 걸 만들고 싶어."
AI: 목적과 보여줄 내용을 질문
흐름 02
정리
IDE용 요청으로 변환
대화가 정리되면 그대로 “AI IDE에게 줄 프롬프트로 바꿔줘”라고 요청합니다.
복사 문장:
"지금까지 내용을 Cursor/Kiro/Windsurf용 코딩 프롬프트로 정리해줘."
흐름 03
실행
AI IDE에 붙여넣기
받은 요청문을 AI IDE 채팅창에 넣고 파일 생성, 실행, 에러 수정을 반복합니다.
AI IDE: 파일 생성 → 실행 → 에러 확인 → 다시 수정
우리는 결과만 보고 방향을 말합니다.
