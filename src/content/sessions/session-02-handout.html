📖 무서운 단어 해석기
localhost
내 컴퓨터 안에서만 열리는 임시 웹사이트인터넷엔 아직 안 올라감
:3000
포트 번호 — "3000번 창구"라는 뜻3001, 8080 등 다를 수 있음
npm
Node 패키지 관리자 — 앱 설치 도구npm install = 필요한 것 설치
node_modules
설치된 패키지들 모아둔 폴더삭제해도 npm install로 복구됨
.env
비밀 설정값 저장 파일 (API 키 등)절대 GitHub에 올리면 안 됨!
API 키
외부 서비스 접근용 비밀번호 같은 것Claude, 카카오, 구글 등
JSON
중괄호로 된 데이터 형식AI가 알아서 써줌 — 외울 필요 없음
git
코드 변경 기록 저장 도구Ctrl+Z의 강력한 버전
deploy
배포 — 인터넷에 올려서 다른 사람도 볼 수 있게Vercel에서 버튼 하나로 가능
build
배포용으로 압축하는 과정npm run build 하면 됨
component
재사용 가능한 화면 조각버튼, 카드, 헤더 등
