Firebase (Google)

초보자 추천
Google이 운영하는 BaaS. 무료 Spark 플랜으로 시작 가능. AI IDE 연동 코드가 많아 초보자에게 최적.
🗄 Firestore
NoSQL 문서형 DB. 실시간 동기화 지원. 컬렉션-문서 구조. 가장 많이 씀.
일정량 무료
⚡ Realtime Database
JSON 기반 실시간 DB. 채팅·라이브 업데이트용. Firestore보다 단순.
일정량 무료
🔐 Firebase Auth
소셜 로그인(Google, GitHub, Apple 등) + 이메일 인증 내장. 가장 쉬운 인증.
무료
📦 Firebase Storage
이미지·파일 저장. 프로필 사진, 첨부파일 등. CDN 내장.
일정량 무료
🌐 Firebase Hosting
정적 사이트 + API 배포. HTTPS 자동. 전 세계 CDN.
무료
⚙ Firebase Functions
서버리스 함수. 결제 처리·알림 발송 등 백엔드 로직 실행.
일정량 무료초과 유료
Firebase 연결 기본 코드
// Firebase 연결 기본 코드
import { initializeApp } from 'firebase/app';
import { getFirestore } from 'firebase/firestore';

const app = initializeApp({
  apiKey: process.env.FIREBASE_API_KEY,
  authDomain: "your-project.firebaseapp.com",
  projectId: "your-project-id",
});

export const db = getFirestore(app);

Supabase

SQL + 오픈소스
PostgreSQL 기반의 오픈소스 Firebase 대안. SQL을 쓸 수 있어 복잡한 데이터 구조에 강함. 무료 플랜으로 시작 가능.
🗄 PostgreSQL DB
실제 SQL 데이터베이스. 관계형 데이터 처리. Row Level Security (RLS)로 보안 관리.
2개 프로젝트 무료
🔐 Auth
소셜 로그인 + 이메일 인증. Magic Link 지원. Firebase Auth와 유사.
무료
📦 Storage
파일 저장. S3 호환 API. RLS로 권한 세밀하게 제어 가능.
1GB 무료
⚙ Edge Functions
Deno 기반 서버리스 함수. 전 세계 엣지 서버에서 실행.
500K 호출 무료
📡 Realtime
DB 변경사항 실시간 구독. 채팅·알림 구현 가능.
무료
🔎 pgvector
AI 벡터 검색 내장. OpenAI 임베딩과 조합해 AI 검색 기능 추가 가능.
무료오픈소스
Supabase 연결 기본 코드
// Supabase 연결 기본 코드
import { createClient } from '@supabase/supabase-js';

const supabase = createClient(
  process.env.SUPABASE_URL,
  process.env.SUPABASE_ANON_KEY
);

// 데이터 조회 예시
const { data, error } = await supabase
  .from('posts')
  .select('*')
  .eq('user_id', userId);

SQL 데이터베이스

관계형 DB
이름특징추천 상황가격
PostgreSQL 가장 강력한 오픈소스 SQL DB. JSON 지원. 벡터 검색 가능 복잡한 데이터 구조 무료 (호스팅 별도)
MySQL / MariaDB 가장 많이 쓰이는 SQL DB. 자료 풍부. LAMP 스택 기본 전통적인 웹 서비스 무료
SQLite 파일 하나가 DB. 설정 없이 사용. 앱 내장 DB, 소규모 서비스 간단한 로컬 앱 무료
PlanetScale 서버리스 MySQL. 브랜치 기능으로 안전한 스키마 변경 스케일업 서비스 무료 플랜 / $39/월~
Neon 서버리스 PostgreSQL. 자동 일시정지로 비용 절감. Vercel과 찰떡 Next.js + Vercel 조합 무료 플랜
CockroachDB 분산 SQL DB. 전 세계 동시 쓰기 가능. 대규모 글로벌 서비스 글로벌 스케일 무료 플랜

NoSQL 데이터베이스

유연한 구조
이름유형특징추천 상황
MongoDB 문서형 JSON 유사 문서 저장. 스키마 유연. Atlas 클라우드 제공 빠른 프로토타입, 유연한 구조
Redis 키-값 (인메모리) 초고속 캐시. 세션 저장. Pub/Sub 메시지 큐 캐시, 실시간 순위, 세션
DynamoDB 키-값/문서 (AWS) AWS 완전 관리형. 무한 확장. Lambda와 조합 최강 AWS 생태계 서비스
Cassandra 와이드 컬럼 쓰기 속도 최강. 대규모 시계열 데이터 로그, IoT 데이터
InfluxDB 시계열 시간 기반 데이터 최적화. 모니터링·센서 데이터 서버 모니터링, 분석

벡터 데이터베이스 (AI용)

AI 검색 필수
AI 검색 기능을 추가할 때 필요합니다. '의미 기반 검색'을 구현하려면 벡터 DB가 필요해요. 일반 키워드 검색과 달리 문장의 '의미'를 이해해서 검색합니다.
Pinecone
AI 검색 전용 클라우드 벡터 DB. 설정 쉽고 빠름. OpenAI 임베딩과 최상의 조합.
무료 플랜Standard $70/월~
Supabase pgvector
Supabase에 내장된 벡터 검색. 추가 설정 없이 SQL과 통합.
무료오픈소스
Weaviate
오픈소스 벡터 DB. 멀티모달(텍스트+이미지) 검색 지원.
오픈소스
Chroma
로컬 개발용 벡터 DB. 설치 간단. AI 프로토타이핑에 최적.
오픈소스
Qdrant
고성능 오픈소스 벡터 DB. 필터링 기능 강함.
오픈소스
Milvus
대규모 벡터 검색 특화. 수십억 벡터 처리 가능.
