API 통신 흐름

요청 → 응답
1
사용자가 버튼 클릭
프론트엔드 — "게시물 불러오기" 버튼 클릭 또는 페이지 로드
2
HTTP 요청 발생
JavaScript 코드가 API 서버로 요청을 보냄
fetch('/api/posts', { method: 'GET' })
3
서버가 요청 수신 & 검증
백엔드 — 로그인 여부 확인, 권한 검사, 요청 유효성 검증
4
데이터베이스 조회
DB에서 필요한 데이터를 가져옴 (SQL 또는 NoSQL)
SELECT * FROM posts WHERE user_id = $1
5
JSON으로 응답 반환
서버가 데이터를 JSON 형태로 포장해서 프론트엔드에 전달
{"posts": [{"id":1, "title":"..."}, ...]}
6
화면에 표시
프론트엔드 — 받은 데이터로 UI를 업데이트해서 사용자에게 보여줌
코드 예시 (Next.js)
// 프론트엔드 코드 (React 컴포넌트)
const response = await fetch('/api/posts');
const data = await response.json();
console.log(data.posts); // [{ id:1, title:'...' }, ...]

// 서버 코드 (Next.js API Route — app/api/posts/route.js)
export async function GET() {
  const posts = await db.collection('posts').get();
  return Response.json({ posts });
}

인증 흐름

로그인 원리
① 이메일 / 비밀번호 로그인
사용자 입력
→
서버로 전송
→
DB 검증
→
JWT 발급
→
브라우저 저장
이후 요청마다 JWT 토큰을 헤더에 포함 → 서버가 사용자 식별
② 소셜 로그인 (Google OAuth)
1
"Google로 로그인" 버튼 클릭
프론트엔드에서 OAuth 플로우 시작
2
Google 인증 서버로 리다이렉트
브라우저가 accounts.google.com으로 이동
3
구글 계정으로 로그인
사용자가 Google 화면에서 계정 선택
4
내 서버로 콜백
Google이 인증 코드와 함께 내 서비스로 돌아옴
5
사용자 정보 저장 & 세션/토큰 발급
이름·이메일·프로필 사진 저장 → JWT 또는 세션 발급 → 로그인 완료
