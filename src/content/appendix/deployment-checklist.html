링크를 공개하기 전 마지막 점검표입니다. 수업에서는 완벽보다 안전한 첫 배포가 목표입니다.

1

로컬 실행 확인

npm install 완료새 컴퓨터에서도 설치 가능한 상태인지 확인
LOCAL
npm run dev 성공브라우저에서 메인 화면이 열리는지 확인
LOCAL
npm run build 성공배포 전 빌드 오류가 없는지 확인
BUILD
콘솔 에러 확인브라우저 개발자도구 Console에 빨간 에러가 없는지 확인
BROWSER
2

보안 확인

.env 파일 GitHub 업로드 금지.gitignore에 .env, .env.local이 있는지 확인
SECRET
API 키 직접 입력 금지코드에 sk-, api_key 같은 값이 박혀 있지 않은지 검색
SECRET
DB 권한 잠금Firebase/Supabase 권한이 모두 허용 상태가 아닌지 확인
DB
개인정보 제거전화번호, 주소, 테스트 계정 비밀번호가 노출되지 않는지 확인
PRIVACY
3

화면 확인

모바일 화면작은 화면에서 버튼과 글자가 겹치지 않는지 확인
UI
핵심 버튼 클릭저장, 제출, 결제, 로그인 같은 핵심 흐름 테스트
FLOW
4

배포 명령어

npm install npm run build # Vercel CLI를 쓰는 경우 vercel vercel --prod
