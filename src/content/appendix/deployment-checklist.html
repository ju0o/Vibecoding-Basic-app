공개 URL을 만들기 전

5강
체크는 문장을 읽었다는 뜻이 아니라, 실제 명령과 실제 URL에서 결과를 확인했다는 뜻입니다.

로컬과 GitHub

`npm run dev`에서 핵심 기능이 작동합니다.
`npm run build`가 오류 없이 끝납니다.
`git status`에서 의도하지 않은 파일과 `.env*`가 보이지 않습니다.
commit 메시지가 이번 변경을 알아볼 수 있게 설명합니다.
올바른 repository와 branch에 push했습니다.

비밀값과 데이터

결제 비밀키, AI API 키, 관리자 DB 주소가 코드와 Console에 직접 보이지 않습니다.
`.env`, `.env.local`이 `.gitignore`에 포함되어 있습니다.
배포 환경에 필요한 Environment Variables를 다시 입력했습니다.
브라우저 공개 변수에 비밀값을 넣지 않았습니다.
비회원·회원·관리자의 데이터 읽기/쓰기 권한이 구분되어 있습니다.
개발 중 모든 읽기/쓰기를 허용한 DB 규칙을 운영 전에 잠갔습니다.

Vercel 확인

Framework, Root Directory, Build Command, Output Directory, Environment Variables, Production URL을 확인합니다.

Firebase 확인

연결된 프로젝트, Hosting public root, SPA 설정, Security Rules, 실제 Hosting URL을 확인합니다.

실제 URL 테스트

시크릿/비로그인 창에서 첫 화면을 열었습니다.
회원가입 또는 로그인 흐름을 확인했습니다.
데이터 추가·조회·수정 중 프로젝트의 핵심 기능을 확인했습니다.
잘못된 입력과 실패 상태의 안내 문구를 확인했습니다.
모바일 크기에서 글자와 버튼이 잘리지 않습니다.
Console과 Network에 반복되는 오류가 없습니다.
