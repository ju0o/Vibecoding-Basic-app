터미널 기초

기본 탐색
터미널이 무섭게 느껴지는 건 당연합니다. 실제로 쓰는 명령어는 10개 내외예요. 아래 목록만 외우면 됩니다.
명령어의미예시
ls  /  dir 현재 폴더의 파일 목록 보기 dir
cd 폴더명 폴더로 이동 cd my-project
cd .. 상위 폴더로 이동 cd ..
pwd 지금 내가 있는 경로 확인 pwd
mkdir 이름 새 폴더 만들기 mkdir my-app
Remove-Item -Recurse -Force 폴더 폴더 삭제 (⚠ 주의 — 복구 불가) Remove-Item -Recurse -Force node_modules
clear 터미널 화면 비우기 clear
Ctrl + C 실행 중인 명령 중단 (개발 서버 종료할 때)

npm 명령어

패키지 관리
기본 프로젝트
# 새 프로젝트 초기화
npm init -y

# 패키지 설치
npm install 패키지명
npm install react react-dom

# 개발용 패키지 (배포 미포함)
npm install -D 패키지명
npm install -D tailwindcss

# 패키지 삭제
npm uninstall 패키지명
프로젝트 실행
# 개발 서버 시작
npm run dev    # 대부분의 프레임워크
npm start       # 구형 방식

# 배포용 빌드
npm run build

# node_modules 재설치
Remove-Item -Recurse -Force node_modules
npm install
Next.js 새 프로젝트 (추천)
npx create-next-app@latest my-app
cd my-app
npm run dev

# → http://localhost:3000 열기
Vite + React 프로젝트
npm create vite@latest my-app -- --template react
cd my-app
npm install
npm run dev

# → http://localhost:5173 열기

Git 명령어

버전 관리
기본 흐름 (매일 쓰는 것)
# 1. 새 저장소 초기화
git init

# 2. 변경사항 스테이징
git add .           # 모든 파일
git add 파일명       # 특정 파일

# 3. 커밋 (변경사항 저장)
git commit -m "feat: 로그인 기능 추가"

# 4. GitHub에 올리기
git push origin main
브랜치 관리
# 브랜치 확인
git branch

# 새 브랜치 만들기
git checkout -b feature/login

# 브랜치 이동
git checkout main

# 브랜치 합치기
git merge feature/login

# 원격 최신 코드 가져오기
git pull origin main
취소 / 되돌리기
# 마지막 커밋 취소 (코드는 유지)
git reset --soft HEAD~1

# 변경사항 전체 되돌리기 (⚠ 주의 — 되돌리기 불가)
git checkout .

# 특정 파일만 되돌리기
git checkout -- 파일명

# 현재 상태 확인
git status
git log --oneline     # 커밋 히스토리 한 줄로
git diff             # 변경된 내용 보기
커밋 메시지 규칙: feat: 새 기능  |  fix: 버그수정  |  docs: 문서  |  style: 스타일  |  refactor: 리팩터  |  chore: 기타
🚀

배포 명령어

세상에 공개
Vercel 배포
# Vercel CLI 설치
npm install -g vercel

# 배포 (처음 — 설정 안내 따라가기)
vercel

# 재배포 (프로덕션)
vercel --prod
GitHub Pages 배포
# gh-pages 패키지 설치
npm install -D gh-pages

# package.json에 추가
"homepage": "https://username.github.io/repo",
"scripts": {
  "predeploy": "npm run build",
  "deploy": "gh-pages -d dist"
}

# 배포 실행
npm run deploy
추천: Vercel에 GitHub 저장소를 연결하면, git push만 해도 자동으로 배포됩니다. CLI 없이도 OK.

유용한 팁

생산성 올리기
탭 자동완성
폴더명·파일명 입력 중 Tab 누르면 자동완성. 오타 방지와 속도 향상에 필수.
명령어 기록
↑ ↓ 방향키로 이전 명령어 재사용. 긴 명령어를 다시 입력할 필요 없음.
.gitignore 필수 항목
반드시 추가해야 할 항목:
node_modules/  .env  .env.local  dist/  .DS_Store
에러 발생 시
빨간 에러 메시지 전체를 복사해서 AI 채팅에 붙여넣기. "이 에러 해결해줘"라고 하면 대부분 바로 해결됩니다.
npm vs npx
npm은 설치, npx는 설치 없이 바로 실행. npx create-next-app처럼 프로젝트 생성 도구에 씀.
Ctrl+C로 종료
개발 서버(npm run dev)가 실행 중일 때 Ctrl+C로 종료. 창을 그냥 닫으면 백그라운드에서 계속 실행될 수 있음.
