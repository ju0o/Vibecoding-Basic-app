VS Code 설치

기반 에디터
코딩 실습의 기본 작업 공간입니다. 먼저 VS Code를 설치하세요. 많은 AI 코딩 도구가 VS Code와 비슷한 구조를 사용해서, 한 번 익히면 다른 도구로 넘어가기 쉽습니다.
1
다운로드
code.visualstudio.com 접속 → 운영체제에 맞게 다운로드 (Windows / Mac / Linux)
2
설치
설치 파일 실행 → 기본 설정으로 Next → Install → Finish. 기본값 그대로 진행하면 됩니다.
3
한국어 설정
Ctrl+Shift+P → "Configure Display Language" 입력 → "ko" 선택 → 재시작
4
터미널 열기
Ctrl+` (백틱) 또는 상단 메뉴 Terminal → New Terminal. 여기서 npm, git 명령어를 입력합니다.
참고: VS Code는 설치만 해도 됩니다. 2회차에서는 VS Code 또는 AI IDE에서 프로젝트 폴더를 열고 터미널을 실행하는 흐름을 연습합니다.

Cursor 설치 & 연동

대표 AI IDE
1
다운로드
cursor.com 접속 → 무료 다운로드 → 설치
2
계정 생성
GitHub 또는 이메일로 가입. 무료 플랜으로 시작 가능.
3
VS Code 설정 가져오기
설치 시 VS Code 확장, 설정, 테마 자동 가져오기 선택 가능. 기존 환경을 그대로 이어받을 수 있음.
4
AI 모델 선택
우측 하단 모델 선택 → 수업 당일 사용 가능한 모델 중 하나를 선택. 처음에는 기본 추천 모델로 시작해도 충분합니다.
5
채팅 시작
Ctrl+L 채팅창 열기 또는 Ctrl+K 인라인 편집. AI에게 자연어로 요청하면 바로 코드 작성.
Cursor 주요 단축키
────────────────────────────────────
Ctrl+L           채팅창 열기 (AI와 대화)
Ctrl+K           현재 코드 AI로 수정
Ctrl+Shift+L     전체 코드베이스 채팅
Tab              AI 자동완성 수락
Esc              AI 제안 거부
Ctrl+Shift+P     명령 팔레트 열기
주의: 무료 제공량과 요금제는 자주 바뀝니다. 처음에는 무료 범위에서 체험하고, 실제로 계속 쓸 도구를 고른 뒤 구독 여부를 결정하세요.

Kiro 설치 & 연동

AWS 제작
1
다운로드
kiro.dev 접속 → 무료 다운로드
2
AWS 계정 연동
화면 안내에 따라 AWS Builder ID 등 필요한 계정으로 로그인합니다.
3
프로젝트 열기
File → Open Folder → 내 프로젝트 폴더 선택
4
AI 채팅 시작
우측 패널 AI 아이콘 클릭 → 채팅 시작. Cursor와 비슷한 인터페이스.
Kiro의 특징 — Spec-driven development: Kiro는 '스펙 주도 개발'이라는 독특한 방식을 씁니다. 요구사항을 먼저 문서로 정의한 후 코드를 생성해서, 결과물이 더 체계적이에요. 처음 체험하기 가장 좋은 도구입니다.
🌌

Antigravity IDE 설치 & 연동

Google 생태계
1
다운로드
antigravity.google 접속 → Antigravity IDE 다운로드
2
Google 계정 연동
Google 계정으로 로그인합니다. 사용 가능한 모델과 제공량은 계정 상태에 따라 달라질 수 있습니다.
3
모델과 권한 확인
설정에서 사용 가능한 모델, 에이전트 권한, 터미널 실행 승인 방식을 확인합니다.
4
채팅 시작
AI에게 계획, 구현, 실행 확인을 요청합니다. 터미널 실행 전에는 어떤 명령인지 꼭 확인하세요.
안전 팁: AI IDE가 터미널 명령을 실행하겠다고 할 때는 삭제 명령, 전체 드라이브 대상 명령, API 키 출력 명령이 아닌지 먼저 확인하세요.

Windsurf 설치 & 연동

AI IDE
1
다운로드
검색창에 Windsurf AI IDE download 입력 → 공식 사이트에서 Windows 또는 Mac 설치 파일 다운로드
2
계정 로그인
화면 안내에 따라 로그인합니다. 무료 제공량과 사용 가능한 모델은 시점에 따라 달라질 수 있습니다.
3
프로젝트 열기
File → Open Folder → 내 프로젝트 폴더 선택. 처음에는 빈 폴더를 열어도 괜찮습니다.
4
AI 채팅 확인
Cascade 또는 AI 채팅창을 열고 “간단한 HTML 페이지 만들어줘”처럼 작은 요청을 입력해봅니다.
추천: Cursor와 Windsurf는 모두 2회차 실습 후보입니다. 둘 중 하나만 준비해도 충분하고, 둘 다 설치해오면 본인에게 맞는 사용감을 비교할 수 있습니다.

유용한 확장 프로그램

생산성 향상
확장 이름기능추천 대상
Prettier 코드 자동 포맷팅. 저장 시 자동 정렬. 들여쓰기·따옴표 통일 모든 사람
ESLint JavaScript 문법 오류 실시간 표시. 빨간 밑줄로 문제 위치 표시 JavaScript 사용자
GitLens Git 변경 이력을 코드에 직접 표시. 누가 언제 수정했는지 확인 Git 사용자
Thunder Client VS Code 내 API 테스트 도구. Postman 대체. API 요청/응답 확인 API 작업 시
DotENV .env 파일 문법 하이라이팅. 환경변수 관리를 쉽게 환경변수 관리 시
Korean Language Pack VS Code 전체 UI를 한국어로 변경 한국어 선호 시
Auto Rename Tag HTML 태그 이름 바꾸면 닫는 태그도 자동으로 함께 변경 HTML 작업 시
Path Intellisense 파일 경로 자동완성. import 경로 입력할 때 파일 목록 제안 파일 임포트 시
확장 프로그램 설치: Ctrl+Shift+X → 이름 검색 → Install 클릭. Cursor·Kiro 등 AI IDE에서도 동일하게 설치 가능합니다.

실전 팁

더 잘 쓰기
터미널 여러 개 열기
터미널 우측 + 버튼으로 탭 추가. 개발 서버 실행 중에 다른 명령어 동시 입력 가능.
멀티 커서
Alt+클릭으로 여러 위치 동시 편집. 같은 내용을 여러 줄에 반복 수정할 때 최강.
파일 빠른 이동
Ctrl+P → 파일명 입력. 마우스 없이 원하는 파일로 빠르게 이동.
전체 텍스트 검색
Ctrl+Shift+F → 프로젝트 전체에서 텍스트 검색. 변수명이나 함수 찾을 때 사용.
AI에게 코드 설명 요청
모르는 코드를 드래그 → Ctrl+L → "이 코드 설명해줘". AI가 한국어로 설명해줌.
에러 메시지 그대로 복사
빨간 에러 메시지 전체를 AI 채팅에 붙여넣기. "이 에러 해결해줘"라고 하면 대부분 바로 해결.
