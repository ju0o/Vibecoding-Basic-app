3

설치 확인 명령어

node -v
npm -v
git --version
code --version

명령어는 VS Code 터미널 또는 PowerShell에서 실행합니다. 버전 숫자가 나오면 성공입니다. "인식되지 않습니다"가 나오면 설치가 안 되었거나 PATH 연결이 빠진 상태입니다.

4

AI 코딩환경 선택 가이드

Cursor

VS Code와 비슷한 사용감의 대표 AI IDE입니다. 처음에는 무료 범위에서 채팅, 코드 수정, 자동완성을 체험합니다.

Kiro

AWS의 agentic coding 도구입니다. 프롬프트를 상세 스펙, 코드, 문서, 테스트로 이어가는 흐름을 연습하기 좋습니다.

Antigravity IDE

Google의 agent-first IDE입니다. 에디터, 터미널, 브라우저를 함께 쓰며 AI가 구현과 검증을 돕는 방향입니다.

Windsurf

AI 에이전트와 자동완성을 활용해 프로젝트를 빠르게 수정하는 AI IDE입니다. Cursor와 함께 2회차 실습 후보로 사용합니다.

Codex CLI

OpenAI의 터미널 기반 코딩 에이전트입니다. Node.js 설치 후 npm으로 설치할 수 있고, 계획과 수정 요약에 강합니다.

npm install -g @openai/codex
codex

Codex CLI는 터미널 사용이 포함되므로 완전 초보라면 2회차 이후에 설치해도 됩니다. 우선 Cursor, Kiro, Antigravity, Windsurf 중 하나를 준비해오면 충분합니다.

6

공식 다운로드 위치

VS Code — 검색창에 Visual Studio Code download 입력 → Microsoft 공식 다운로드 페이지에서 Stable 버전 설치
Node.js — 검색창에 Node.js LTS download 입력 → 공식 Node.js 사이트에서 Windows Installer 설치
Git for Windows — 검색창에 Git for Windows download 입력 → 공식 Git 사이트에서 Windows용 설치 파일 다운로드
Cursor — 검색창에 Cursor AI editor download 입력 → Cursor 공식 사이트에서 Windows 설치 파일 다운로드
Kiro — 검색창에 Kiro AI IDE download 또는 AWS Kiro 입력 → 공식 안내 페이지에서 설치 가능 여부 확인
Antigravity — 검색창에 Google Antigravity IDE 입력 → Google 공식 제품 페이지에서 설치 안내 확인
Windsurf — 검색창에 Windsurf AI IDE download 입력 → Windsurf 공식 사이트에서 Windows 또는 Mac 설치 파일 다운로드
Codex CLI — Node.js 설치 후 터미널에서 npm install -g @openai/codex 입력 → codex로 실행
