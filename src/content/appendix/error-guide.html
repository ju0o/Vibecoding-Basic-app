별첨 자료

에러 해결 가이드

코딩보다 중요한 것은 막혔을 때 다시 굴리는 능력입니다. 에러는 실패가 아니라 AI에게 더 정확한 정보를 줄 기회입니다.

1

막혔을 때 해결 루프

STEP 01멈추기아무 명령이나 더 치지 않기
STEP 02복사에러 전체와 명령어 복사
STEP 03상황 설명무엇을 하려 했는지 추가
STEP 04AI에게 요청원인, 해결 순서 받기
STEP 05하나씩 실행한 번에 하나만 적용
2

AI에게 꼭 줘야 하는 정보

COMMAND
내가 입력한 명령어

예: npm run dev, npm install, git push

ERROR
빨간 에러 전체

마지막 한 줄만 보내면 원인을 놓칠 수 있습니다.

CONTEXT
지금 하려던 일

설치 중인지, 실행 중인지, 배포 중인지 알려주세요.

3

대표 에러 빠른 해석

command not found / 인식되지 않습니다
프로그램이 설치되지 않았거나 PATH 연결이 빠진 상태입니다. 설치 후 터미널을 새로 여세요.
Cannot find module
필요한 패키지가 없거나 node_modules가 깨졌습니다. 보통 npm install로 해결합니다.
EADDRINUSE / port already in use
이미 같은 포트에서 서버가 실행 중입니다. 기존 서버를 Ctrl+C로 끄거나 다른 포트를 씁니다.
npm ERR!
npm 설치/실행 단계에서 난 오류입니다. 에러 전체와 package.json을 AI에게 보여주세요.
4

그대로 붙여넣는 에러 해결 프롬프트

나는 바이브코딩 기초반 수강생이고, 지금 웹 프로젝트를 실행/수정하는 중이야. 내가 하려던 일: [여기에 상황 작성] 내가 입력한 명령어: [여기에 명령어 작성] 나온 에러 전체: [여기에 에러 전체 붙여넣기] 내 환경: Windows / PowerShell / VS Code / Node.js 사용 중 위 에러의 원인을 초보자도 이해할 수 있게 설명해주고, 해결 명령어를 한 번에 하나씩 순서대로 알려줘. 위험한 삭제 명령이 있으면 먼저 경고해줘.
