사용 방식Windows/Mac 중 본인 환경만 따라 하고, 2회차 시작 전 확인 명령어를 보여줍니다.
배포 안내링크 대신 검색어와 공식 사이트 위치를 안내합니다. 설치 후 터미널을 새로 열어 확인합니다.
SESSION 02 PREP · WINDOWS / MAC

2회차 바이브코딩
사전 준비자료

2회차에서는 바로 실습에 들어갑니다. 아래 항목을 설치하고, 터미널에서 버전 숫자가 나오는지만 확인해오면 충분합니다.

필수 1

Node.js LTS 설치 후 node -v, npm -v 확인

필수 2

VS Code 설치 후 터미널 열기까지 확인

선택 1개 이상

Cursor, Kiro, Antigravity, Windsurf 중 하나 설치

1. 터미널 여는 방법
Windows
PowerShell
1
시작 메뉴에서 PowerShell 또는 터미널 검색 후 실행
2
VS Code에서는 상단 메뉴 Terminal → New Terminal 클릭
3
단축키는 보통 Ctrl + ` 입니다.
4
현재 폴더 확인: pwd 또는 cd
Mac
Terminal
1
Cmd + Space → Terminal 검색 후 실행
2
Finder → Applications → Utilities → Terminal 실행도 가능합니다.
3
VS Code에서는 상단 메뉴 Terminal → New Terminal 클릭
4
현재 폴더 확인: pwd
2. Node.js LTS 설치
Windows 설치
필수
1
검색창에 Node.js LTS download 입력
2
공식 Node.js 사이트에서 Windows Installer 다운로드
3
설치 옵션은 기본값으로 진행합니다. PATH 추가는 기본 체크 상태를 유지합니다.
4
새 터미널에서 node -v, npm -v 확인
Mac 설치
필수
1
검색창에 Node.js LTS download 입력
2
공식 Node.js 사이트에서 macOS Installer 다운로드
3
Homebrew 사용자라면 brew install node도 가능합니다.
4
새 터미널에서 node -v, npm -v 확인
3. VS Code 설치
Windows
편집기
검색창에 Visual Studio Code download 입력 → Microsoft 공식 페이지 → Windows용 Stable 설치 파일 다운로드.
설치 후 VS Code 실행 → Terminal → New Terminal → node -v 입력
Mac
편집기
검색창에 Visual Studio Code download 입력 → Microsoft 공식 페이지 → Mac용 다운로드. Apple Silicon/Intel 선택이 나오면 본인 Mac에 맞게 선택합니다.
설치 후 VS Code 실행 → Terminal → New Terminal → node -v 입력
설치했는데 node가 인식되지 않으면 터미널을 완전히 닫았다가 다시 열어보세요. 그래도 안 되면 PC를 재부팅하거나 Node.js를 다시 설치합니다.
SESSION 02 PREP · AI CODING IDE

AI 코딩환경 설치
Cursor · Kiro · Antigravity · Windsurf

아래 도구를 전부 설치할 필요는 없습니다. 2회차 실습 전에는 네 가지 중 하나만 준비해도 됩니다. 가능하면 두 개 정도 설치해두면 비교가 쉽습니다.

4. AI 코딩 도구 설치 위치
Cursor
추천
어디서 찾나요?
검색창에 Cursor AI editor download 입력 → Cursor 공식 사이트 → Windows 또는 Mac 다운로드.
설치 후 확인: 로그인 → 새 폴더 열기 → AI 채팅창에 “이 프로젝트 설명해줘” 입력
Kiro
설계형
어디서 찾나요?
검색창에 Kiro AI IDE download 또는 AWS Kiro 입력 → 공식 안내 페이지에서 설치.
설치 후 확인: 로그인 → 프로젝트 폴더 열기 → 요구사항을 먼저 정리해달라고 요청
Antigravity
Agent IDE
어디서 찾나요?
검색창에 Google Antigravity IDE 입력 → Google 공식 제품 페이지에서 설치 안내 확인.
설치 후 확인: Google 계정 로그인 → AI 패널과 터미널 실행 권한 확인
Windsurf
AI IDE
어디서 찾나요?
검색창에 Windsurf AI IDE download 입력 → Windsurf 공식 사이트에서 Windows 또는 Mac 다운로드.
설치 후 확인: 로그인 → Cascade/AI 채팅 열기 → “간단한 HTML 페이지 만들어줘” 입력
