AI 작업지시서 템플릿

프롬프트를 외우지 않아도 됩니다. 상황에 맞는 템플릿을 붙여넣고 빈칸만 채우면, AI가 다음 작업을 도와줍니다.

1

템플릿 사용 흐름

GPT/Gemini/Claude

아이디어를 설계하고, AI IDE용 프롬프트로 정리합니다.

Cursor/Kiro/Antigravity/Codex

정리된 지시문을 바탕으로 실제 코드를 수정합니다.

2

프로그램 설계 요청

나는 지금부터 [사이트/프로그램 이름]을 만들려고 해. 목적: [누구의 어떤 문제를 해결하는지] 넣고 싶은 기능: 1. [기능 1] 2. [기능 2] 3. [기능 3] 원하는 디자인 분위기: [예: 어두운 배경, 깔끔한 대시보드, 모바일 친화적] 나와 대화하면서 빠진 요구사항을 질문해주고, 마지막에는 MVP로 만들 최소 기능과 화면 구성을 정리해줘.
3

AI IDE용 구현 지시문 만들기

위에서 정리한 내용을 바탕으로 Cursor/Kiro/Antigravity/Codex에게 줄 구현 프롬프트를 작성해줘. 형식: 1. 역할 2. 목표 3. 구현할 화면/기능 4. 디자인 조건 5. 제약사항 6. 구현 후 확인할 테스트 7. 마지막에 README 또는 작업 요약 md 작성 초보자가 그대로 붙여넣을 수 있게 명확하고 단계적으로 작성해줘.
4

현재 코드 수정 요청

현재 프로젝트에서 아래 문제를 고치고 싶어. 문제: [무엇이 안 되는지] 원하는 결과: [어떻게 바뀌면 좋은지] 현재 화면/에러/코드: [캡처 내용 또는 에러 또는 코드 붙여넣기] 먼저 원인을 설명하고, 수정해야 할 파일 목록과 수정 순서를 알려줘. 그 다음 실제 수정 프롬프트를 작성해줘.
5

작업 요약 md 요청

지금까지 작업한 내용을 프로젝트 문서로 정리해줘. 포함할 내용: - 프로젝트 목적 - 주요 기능 - 사용한 기술 - 실행 방법 - 현재 완성된 부분 - 아직 남은 문제 - 다음 작업 우선순위 5개 README.md 또는 PROJECT_SUMMARY.md에 넣기 좋은 형태로 작성해줘.

수업에서는 "설계 AI"와 "구현 AI IDE"를 나눠 쓰면 결과가 더 안정적입니다.
