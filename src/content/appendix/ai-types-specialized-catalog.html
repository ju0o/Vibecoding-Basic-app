APPENDIX · SESSION 01

AI 종류별 특화 도구 가이드

AI는 하나의 만능 프로그램이 아니라, 결과물에 따라 강점이 다른 도구들의 묶음입니다. 이 자료는 1회차에서 각 AI가 어떤 일에 강한지 설명할 때 사용합니다.

1. 생각 · 문서 · 학습 AI
ChatGPT / GPT
GENERAL

특화 역할: 범용 대화, 아이디어 정리, 글쓰기, 학습, 코딩 보조까지 넓게 사용합니다.

추천 사용: “내가 하려는 일을 정리해줘”, “AI 코딩 툴에 줄 프롬프트로 바꿔줘”.
Claude
READING / CODE

특화 역할: 긴 문서 읽기, 논리적 정리, 코드 설명, 복잡한 요구사항 분석에 강합니다.

추천 사용: 긴 기획서 요약, 프로젝트 코드 설명, 오류 원인 추론.
Gemini
MULTIMODAL

특화 역할: 텍스트뿐 아니라 이미지, 화면, 자료를 함께 이해하는 멀티모달 작업에 적합합니다.

추천 사용: 스크린샷 분석, 구글 생태계 자료 정리, 이미지 기반 설명.
NotebookLM
MY SOURCES

특화 역할: 내가 넣은 PDF, 문서, 영상 자료를 기반으로 요약과 Q&A를 합니다.

추천 사용: 강의자료 요약, 내 자료 기반 질의응답, 수업 복습.
Perplexity
SEARCH

특화 역할: 검색과 답변을 결합해 비교 조사, 최신 정보 확인, 출처 기반 리서치에 씁니다.

추천 사용: 도구 비교, 개념 조사, 참고자료 찾기.
Grok
REALTIME

특화 역할: 실시간 이슈, SNS 흐름, 빠른 트렌드 파악에 쓰는 대화형 AI입니다.

추천 사용: 현재 이슈 요약, 시장 반응 파악, 콘텐츠 아이디어 탐색.
2. 이미지 · 디자인 AI
Nano Banana
IMAGE EDIT

특화 역할: 이미지 생성과 수정, 제품 합성, 인물·배경 변경 등 시각 결과물 편집에 사용합니다.

추천 사용: 상세페이지 이미지, 프로필 이미지, 전후 비교 이미지.
Midjourney
VISUAL

특화 역할: 감각적인 이미지, 콘셉트 아트, 브랜드 무드보드, 썸네일 제작에 강합니다.

추천 사용: 강의 썸네일, SNS 비주얼, 제품 콘셉트 시안.
Adobe Firefly
DESIGN

특화 역할: 디자인 작업 흐름과 연결하기 좋고, 브랜드 이미지·광고 소재 제작에 적합합니다.

추천 사용: 배너 시안, 포스터 배경, 디자인 소스 생성.
Canva AI
TEMPLATE

특화 역할: 템플릿 기반 카드뉴스, 발표자료, 간단한 디자인 편집에 편합니다.

추천 사용: 빠른 카드뉴스, 발표 표지, 수업 안내 이미지.
APPENDIX · SESSION 01

AI 종류별 특화 도구 가이드 · 2

영상, 코딩, 자동화 도구는 실제 결과물을 만드는 단계에서 자주 사용합니다. 2회차 바이브코딩 실습은 이 중 AI 코딩 도구를 중심으로 진행합니다.

3. 영상 · 음성 · 미디어 AI
Veo
VIDEO

특화 역할: 텍스트나 이미지에서 영상 장면을 생성해 홍보 영상, 쇼츠, 데모 컷에 활용합니다.

추천 사용: 제품 소개 영상, 강의 홍보 장면, 움직이는 예시 컷.
Sora
VIDEO

특화 역할: 프롬프트 기반 영상 생성과 장면 연출에 사용합니다.

추천 사용: 브랜드 영상, 서비스 소개 컷, 상상 장면 시각화.
Runway
VIDEO EDIT

특화 역할: 영상 생성, 편집, 배경 제거, 움직임 보정 등 미디어 제작 도구로 활용합니다.

추천 사용: 쇼츠 편집, 영상 스타일 변경, 프로토타입 영상.
ElevenLabs
VOICE

특화 역할: 음성 합성, 내레이션, 다국어 더빙 등 목소리 기반 콘텐츠 제작에 사용합니다.

추천 사용: 강의 내레이션, 홍보 영상 음성, 앱 안내 음성.
4. 바이브코딩 · 개발환경 AI
Cursor
AI IDE

특화 역할: VS Code와 비슷한 화면에서 AI가 코드를 읽고, 수정하고, 새 파일을 만듭니다.

추천 사용: 초보자의 첫 웹페이지 생성, 오류 수정, 기능 추가.
Windsurf
AI IDE

특화 역할: 에이전트 기반 코딩 흐름과 자동완성으로 프로젝트를 빠르게 수정합니다.

추천 사용: 무료 범위 체험, 빠른 수정, 코드 설명 요청.
Kiro
SPEC

특화 역할: 요구사항과 설계를 먼저 정리한 뒤 구현하는 스펙 주도 개발 흐름에 적합합니다.

추천 사용: 만들 기능을 문서로 정리하고, 단계별 구현을 맡길 때.
Antigravity
AGENT IDE

특화 역할: 에디터, 터미널, 브라우저를 함께 보며 AI가 구현과 실행 확인을 돕는 개발환경입니다.

추천 사용: Gemini 기반 AI IDE를 쓰고 싶을 때, 실행 확인까지 맡기고 싶을 때.
5. 자동화 · 에이전트 AI
도구특화 역할수업에서 보는 관점
Manus여러 단계를 스스로 계획하고 실행하는 범용 에이전트형 AI기초반에서는 개념 소개, 응용반에서 고도화 주제로 연결
n8n서비스와 서비스를 연결해 반복 작업을 자동화하는 워크플로 도구뉴스 수집, 메일 분류, 알림 발송 같은 자동화 예시
Zapier코딩 없이 앱 사이의 자동화 흐름을 만드는 도구폼 제출 → 메일 발송 → 시트 기록 같은 업무 자동화
GitHub Copilot코드 자동완성, 코드 설명, VS Code 기반 개발 보조기존 개발자가 쓰는 AI 보조 도구의 예시
