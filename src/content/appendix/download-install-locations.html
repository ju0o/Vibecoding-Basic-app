APPENDIX B · PRECLASS SETUP

설치 · 다운로드
위치 안내

수강생이 링크를 잃어버려도 준비할 수 있도록, 검색어와 공식 다운로드 위치, 설치 후 확인 명령어를 프린트용으로 정리했습니다.

1

무엇을 어디서 설치하나요?

Node.js LTS

npm 명령어와 개발 서버 실행에 필요합니다.

찾는 방법
검색창에 Node.js LTS download 입력 → 공식 Node.js 사이트 → Windows Installer 다운로드
설치 후 확인
node -v
npm -v
Git for Windows

GitHub 업로드, 버전 관리, 배포 연결에 필요합니다.

찾는 방법
검색창에 Git for Windows download 입력 → 공식 Git 사이트 → Windows 다운로드
설치 후 확인
git --version
Visual Studio Code

기본 코드 편집기입니다. AI IDE가 어렵다면 VS Code부터 시작합니다.

찾는 방법
검색창에 Visual Studio Code download 입력 → Microsoft 공식 페이지 → Stable 버전 설치
설치 후 확인
프로그램 실행 → Terminal 메뉴 → New Terminal 클릭
Cursor

AI가 코드 작성과 수정에 직접 참여하는 AI IDE입니다.

찾는 방법
검색창에 Cursor AI editor download 입력 → Cursor 공식 사이트 → Windows 설치 파일 다운로드
설치 후 확인
로그인 → 프로젝트 폴더 열기 → AI 채팅창에 hello 입력
Kiro

요구사항과 작업 계획을 잡아가며 개발하는 AI IDE입니다.

찾는 방법
검색창에 Kiro AI IDE download 또는 AWS Kiro 입력 → 공식 안내 페이지 확인
설치 후 확인
로그인 → 새 폴더 열기 → AI에게 프로젝트 설명 요청
Antigravity

Google Gemini 기반의 AI 코딩환경을 체험할 때 사용합니다.

찾는 방법
검색창에 Google Antigravity IDE 입력 → Google 공식 제품 페이지에서 설치 안내 확인
설치 후 확인
Google 계정 로그인 → 프로젝트 폴더 열기 → AI 패널 확인
Windsurf

AI 에이전트와 자동완성으로 프로젝트를 빠르게 수정하는 AI IDE입니다.

찾는 방법
검색창에 Windsurf AI IDE download 입력 → Windsurf 공식 사이트 → Windows 또는 Mac 설치 파일 다운로드
설치 후 확인
로그인 → 프로젝트 폴더 열기 → Cascade 또는 AI 채팅창에 간단한 요청 입력
2

2회차 전 확인 명령어

Node 설치 확인
node -v 입력 후 v로 시작하는 숫자가 나오면 정상입니다.
npm 설치 확인
npm -v 입력 후 숫자가 나오면 정상입니다.
Git 설치 확인
git --version 입력 후 git version 문장이 나오면 정상입니다.
현재 위치 확인
pwd 또는 cd로 터미널이 어느 폴더를 보고 있는지 확인합니다.
3

다운로드가 안 될 때

공식 사이트인지 확인: 광고로 뜨는 다운로드 버튼보다, 검색 결과에서 제작사 이름이 보이는 공식 페이지를 우선합니다.
회사·학교 PC 제한: 설치 권한이 막혀 있으면 개인 노트북에서 준비하거나 관리자 권한을 요청합니다.
인터넷이 느릴 때: 설치 파일만 먼저 다운로드해두고, 수업 전 와이파이가 안정적인 곳에서 설치를 마칩니다.
설치 후 재시작: 명령어가 안 먹으면 터미널을 완전히 닫고 다시 열거나, PC를 재부팅합니다.
