프론트엔드 용어

사용자가 보는 화면
용어쉬운 설명예시
HTML 웹페이지의 뼈대. 제목, 문단, 버튼 등의 구조를 담당 <h1>제목</h1>
CSS 뼈대에 입히는 디자인. 색상, 크기, 위치 등 스타일 결정 color: red; font-size: 20px;
JavaScript 웹페이지를 움직이게 하는 코드. 버튼 클릭, 데이터 처리 클릭 시 팝업 표시, 데이터 불러오기
React Facebook이 만든 UI 라이브러리. 컴포넌트(부품)를 조합해 페이지 구성 네이버·당근마켓도 사용
Next.js React 기반 프레임워크. SEO, 라우팅, 배포가 쉬워짐 가장 인기 있는 풀스택 도구
TypeScript JavaScript에 타입을 추가한 언어. 오류를 미리 잡아줌 const name: string = "홍길동"
Tailwind CSS 클래스 이름으로 스타일을 적용하는 CSS 도구. AI IDE가 잘 씀 className="text-lg font-bold"
컴포넌트 재사용 가능한 UI 부품. 헤더, 버튼, 카드 등 React의 기본 단위
상태 (State) 컴포넌트가 기억하는 데이터. 변하면 화면이 다시 그려짐 좋아요 수, 로그인 여부
Props 부모 컴포넌트가 자식에게 전달하는 데이터 <Button color="blue" />
API 호출 서버에 데이터를 요청하는 행위. fetch() 또는 axios 사용 날씨 데이터 가져오기
렌더링 코드를 실제 화면으로 그려내는 과정 HTML → 브라우저 화면

백엔드 용어

서버 & 데이터
용어쉬운 설명예시/비유
서버 요청을 받아 처리하고 응답을 돌려주는 컴퓨터/프로그램 식당의 주방
API 프로그램끼리 대화하는 규칙/통로. 프론트↔백엔드 통신 방법 웨이터 (주문 전달)
REST API URL로 자원을 주고받는 가장 일반적인 API 방식 GET /users POST /posts
엔드포인트 API에서 특정 기능에 접근하는 URL 주소 /api/login /api/posts/123
데이터베이스 (DB) 데이터를 체계적으로 저장하고 꺼낼 수 있는 창고 엑셀의 고급 버전
ORM 코드로 DB를 다루는 도구. SQL 직접 안 써도 됨 Prisma, Drizzle
미들웨어 요청이 처리되기 전에 실행되는 중간 코드 로그인 확인, 요청 검사
환경변수 코드에 직접 쓰면 안 되는 비밀값. .env 파일에 저장 API Key, DB 비밀번호
서버리스 서버를 직접 관리 안 해도 되는 방식. 함수 단위로 실행 Firebase Functions, Vercel Edge
CORS 다른 주소에서 API 요청할 때 발생하는 보안 제한 프론트(3000)→백엔드(8000) 요청 시
JWT 로그인 상태를 저장하는 토큰. 서버가 사용자를 식별하는 방법 로그인 후 받는 열쇠
웹훅 (Webhook) 이벤트 발생 시 자동으로 URL을 호출하는 방식 결제 완료 → 내 서버 자동 알림

DevOps / 배포 용어

서비스 운영
용어쉬운 설명예시/비유
배포 (Deploy) 만든 서비스를 실제 서버에 올려 누구나 접근 가능하게 하는 것 앱을 세상에 공개
빌드 (Build) 소스코드를 실행 가능한 파일로 변환하는 과정 npm run build
CI/CD 코드 변경 시 자동으로 테스트·배포하는 파이프라인 GitHub Actions
Docker 앱을 컨테이너(박스)에 담아 어디서든 같은 환경으로 실행 이사할 때 박스 포장
Vercel Next.js에 최적화된 배포 플랫폼. GitHub 연결 → 자동 배포 가장 쉬운 배포 방법
CDN 전 세계 서버에 콘텐츠를 분산 저장해 빠르게 제공하는 시스템 Cloudflare, Vercel Edge
도메인 사람이 읽을 수 있는 웹 주소 myapp.com, naver.com
HTTPS 암호화된 보안 연결. 자물쇠 아이콘. 배포 시 필수 Vercel은 자동 제공
환경 개발(dev)/스테이징(staging)/운영(production) 서버 구분 개발서버 vs 실제서버

AI 관련 용어

바이브코딩 핵심
용어쉬운 설명예시
LLM 거대 언어 모델. ChatGPT·Claude 같은 AI의 핵심 기술 GPT-4o, Claude Sonnet
프롬프트 AI에게 주는 지시문. 어떻게 쓰느냐에 따라 결과가 완전히 달라짐 "너는 마케터야. 광고 카피 써줘."
토큰 AI가 텍스트를 처리하는 단위. 1토큰 ≈ 글자 0.75개 입출력 비용의 기준
컨텍스트 윈도우 AI가 한 번에 처리할 수 있는 최대 토큰 수 Claude: 200K 토큰 (책 한 권)
임베딩 텍스트를 숫자 벡터로 변환. 의미 기반 검색의 기반 유사한 문장 → 가까운 벡터
RAG 검색+AI 조합. 내 데이터베이스에서 관련 정보 찾아 AI에게 전달 AI 고객지원 챗봇
파인튜닝 기존 AI 모델을 내 데이터로 추가 학습시키는 것 내 글투로 말하는 AI
시스템 프롬프트 AI의 역할·규칙을 설정하는 숨은 프롬프트 "항상 한국어로 답하고, 친절하게"
할루시네이션 AI가 사실이 아닌 것을 자신감 있게 말하는 현상 없는 논문 인용, 잘못된 코드
멀티모달 텍스트+이미지+음성 등 여러 형태를 처리하는 AI GPT-4o, Gemini 2.0

웹 기초 용어

인터넷 원리
용어쉬운 설명
URL 웹 주소. https://도메인/경로?쿼리=값 형태
HTTP / HTTPS 웹 통신 규약. HTTPS는 암호화된 안전한 버전. 브라우저 자물쇠 아이콘
GET / POST 데이터 요청(GET) vs 데이터 전송(POST). API의 기본 동작 방식
JSON 데이터 교환 표준 형식. {"name":"홍길동","age":30}
쿠키 브라우저에 저장되는 작은 데이터. 로그인 상태 유지에 사용
세션 서버가 사용자를 기억하는 기간. 로그아웃하면 종료
캐시 자주 쓰는 데이터를 임시 저장해 빠르게 제공. 브라우저 '새로고침'으로 초기화
반응형 화면 크기(PC/태블릿/모바일)에 따라 레이아웃이 자동 변경되는 디자인
SEO 검색엔진 최적화. Google 검색 결과에 잘 나오게 하는 기술
오픈소스 소스코드가 공개된 소프트웨어. 무료로 사용하고 수정할 수 있음
라이브러리 자주 쓰는 기능을 모아 놓은 코드 묶음. 가져다 쓰면 됨
프레임워크 개발 전체 구조를 제공하는 틀. 라이브러리보다 더 큰 개념
