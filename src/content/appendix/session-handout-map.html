회차별 별첨자료
활용 맵

1~6회차에서 수강생에게 나눠줄 프린트물과 강사가 따로 볼 대본·공부자료를 구분해 정리한 강사용 운영표입니다.

1

회차별 자료 배포 순서

1회차
강의 주제
AI는 도구다
다양한 AI 도구와 바이브코딩 준비물을 이해합니다.
수강생 배포자료
1~6강 커리큘럼 1페이지 요약
AI 종류별 특화 도구 가이드
AI 도구 완전 가이드
2회차 사전 준비자료
사용 방식
시작 전 커리큘럼 요약을 나눠주고, 마지막 5분에 Node, VS Code, AI IDE 설치 숙제를 배포합니다. 강사용: 1강 대본 + 강사용 공부자료.
2회차
강의 주제
바이브코딩 첫 실습
AI에게 설계시키고, AI IDE에 작업을 맡기는 흐름을 익힙니다.
수강생 배포자료
명령어 치트시트
AI 작업지시서 템플릿
MVP 기획 워크시트
수강생 실습 기록지
사용 방식
실습 전에 명령어와 작업지시서만 먼저 보여주고, 30분 실습 뒤 기록지를 작성하게 합니다. 강사용: 2강 대본 + 강사용 공부자료.
3회차
강의 주제
개발 용어 이해
프론트, 백엔드, API, DB의 위치와 연결 흐름을 비유와 화면으로 이해합니다.
수강생 배포자료
UI/UX·프론트엔드 용어 정리
3강 수강생 한 장 요약
한 기능 완성 점검 워크시트
프로그램 구조 시각적 다이어그램
AI 작업지시서 템플릿
사용 방식
수강생에게는 용어 프린트물만 배포하고, 강사용 대본은 발표자가 화면 비유와 클릭 순서를 리허설할 때 사용합니다. 강사용: 3강 대본 + 강사용 공부자료.
4회차
강의 주제
파일 구조 이해
AI가 만든 프로젝트에서 어떤 파일을 봐야 하는지 익힙니다.
수강생 배포자료
프로젝트 폴더 구조 설명
4강 프로젝트 파일 지도 + 파일 추적 워크시트
명령어 치트시트
에러 해결 가이드
사용 방식
프로젝트 폴더를 직접 열고 브라우저 화면 → 검색어 → 페이지·컴포넌트·스타일 파일 → 수정 결과를 워크시트에 기록하게 합니다. 강사용: 4강 12장 상세 대본 + 강사용 공부자료.
5회차
강의 주제
배포와 보안 그리고 데이터
내 컴퓨터의 프로젝트를 인터넷으로 공개하기 전 필요한 개념을 봅니다.
수강생 배포자료
데이터베이스 완전 가이드
5강 서비스 공개 점검표
배포 전 체크리스트
시각적 다이어그램
사용 방식
환경변수와 API 키는 “절대 공개하지 않는 메모”로 표시하고, 배포 전 체크리스트를 함께 훑습니다. 강사용: 5강 대본 + 강사용 공부자료.
6회차
강의 주제
쇼케이스 발표
각자 만든 프로그램을 보여주고, 다음 개선 방향을 정합니다.
수강생 배포자료
발표 템플릿
6강 쇼케이스 발표지
수강생 실습 기록지
응용반 예고 · 기능 확장 아이디어
사용 방식
기술 설명보다 “무엇을 만들었고, 어디까지 작동하고, 다음에 무엇을 붙일지”에 집중합니다. 강사용: 6강 대본 + 강사용 공부자료.
2

추천 출력 묶음

1회차 종료 숙제 묶음

사전 준비 체크리스트 + 설치·다운로드 위치 안내 + VSCode & AI IDE 셋업 가이드. 2회차 실습 준비용입니다.

실습 테이블 기본 묶음

명령어 치트시트 + AI 작업지시서 템플릿 + 에러 해결 가이드 + 실습 기록지. 2~5회차 매번 책상에 둡니다.

발표 준비 묶음

MVP 기획 워크시트 + 발표 템플릿 + 기능 확장 아이디어. 6회차 발표와 응용반 연결에 사용합니다.

강사용 리허설 묶음

1~6강 강사용 대본 + 강사용 공부자료. 수업 전 동선, 클릭 순서, 질문 대응 범위를 확인할 때 사용합니다.

프린트 배포 방식

권장: 모든 자료를 처음부터 한꺼번에 나눠주기보다, 회차별로 필요한 종이만 꺼내 주세요. 수강생 배포자료와 강사용 대본은 분리해서 출력하고, 실습 중에는 “명령어 치트시트 · AI 작업지시서 · 에러 해결 가이드” 세 장만 책상 위에 두는 것이 가장 좋습니다.
