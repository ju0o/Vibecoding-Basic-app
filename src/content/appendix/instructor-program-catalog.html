B01 · 바이브코딩 기초반

AI 이해, 바이브코딩, 개발 용어, 파일 구조, 배포·보안·데이터, 쇼케이스. 완벽한 코드를 쓰는 법이 아니라 AI가 만든 결과의 위치와 흐름을 판단하는 법을 가르칩니다.

A01 · 응용·수익화반

고객 문제, MVP, 가격·결제, 상품 화면, 작은 출시, 제품 지표. 기능을 많이 만드는 것보다 사용·결제할 이유를 검증합니다.

P02 · AI SaaS 제작·출시반

가입, 권한, 결제, 운영자 도구와 제품 지표를 연결합니다. 응용반 이후 실제 서비스 구조를 구현하려는 수강생에게 적합합니다.

P03 · 포트폴리오·외주 실전반

사례 서사, 요구사항, 견적, 수정 범위, 검수와 인수인계를 다룹니다. 결과물뿐 아니라 고객과의 작업 계약을 가르칩니다.

W01 · AI 업무자동화 구축반

트리거, 액션, API, 웹훅, 실패·재시도와 승인 지점을 설계합니다. 자동화 전에 반복성과 위험을 먼저 평가합니다.

X01 · AI 워크스페이스 심화반

MCP, Skill, Agent, Agent Teams, 개인 AI 워크스페이스와 운영·평가·복구를 강의 중심으로 연결하는 상위 개론입니다.

G01 · MCP 연결 설계반

Host, Client, Server, Tool, 인증, 권한과 감사 로그를 깊게 다룹니다. 연결 수가 아니라 안전한 도구 계약이 목표입니다.

G02 · AI Skill 제작반

반복 업무를 한 가지 책임, 입력, 절차, 산출물과 검증 기준이 있는 재사용 작업으로 표준화합니다.

G03 · AI Agent 설계반

계획, 도구 선택, 컨텍스트, 메모리, 평가, 복구와 비용을 갖춘 실행 루프를 설계합니다.

G04 · Agent Teams 설계반

역할 경계, 병렬 작업, 공통 산출물, Reviewer와 Human Lead를 정의해 여러 Agent의 충돌을 줄입니다.

T01 · Claude Code 실전반

CLAUDE.md, 프로젝트 탐색, diff, MCP, 장기 세션과 subagent를 Claude Code의 공식 구조에 맞춰 학습합니다.

T02 · OpenAI Codex 실전반

AGENTS.md, Skills, Plugins, MCP, 브라우저 검증, subagents와 GitHub 릴리즈 운영을 Codex의 작업 모델에 맞춰 학습합니다.

I01 · 바이브코딩 강사 양성과정

비개발자 인지 부하, 설명 애니메이션, SAY/DO 대본, 실습 오류 대응과 과정 개선 시스템을 다룹니다.

선수 과정과 추천 순서

모든 수강생은 B01 기초반 또는 이에 준하는 파일·배포·데이터 이해가 필요합니다.
수익 목적은 A01 이후 P02 SaaS 또는 P03 외주 중 하나로 분기합니다.
업무 효율 목적은 W01 자동화 이후 X01 심화, G01 MCP 순서가 안정적입니다.
G02 Skill은 반복 작업 경험이 생긴 뒤, G03 Agent는 도구와 검증 기준을 이해한 뒤 진행합니다.
G04 Agent Teams는 단일 Agent의 실패와 복구를 경험한 수강생을 대상으로 합니다.
T01과 T02는 우열 과정이 아닙니다. 사용하는 도구와 업무 환경에 따라 별도로 선택합니다.

강사가 공부할 우선순위

1단계 · 직접 사용

각 도구로 작은 프로젝트를 시작하고 파일 수정, 테스트, Git commit, 배포까지 한 사이클을 경험합니다.

2단계 · 실패 수집

권한 거부, 잘못된 경로, build 실패, 환경변수 누락과 Agent 오판 사례를 수업용으로 기록합니다.

3단계 · 설명 설계

한 슬라이드에서 한 가지 판단만 배우도록 시각화하고, 강사가 단계별로 수동 진행할 수 있게 합니다.

4단계 · 최신성 점검

도구 화면, 설치 방법, 요금과 기능은 변하므로 수업 직전 공식 문서와 실제 계정 화면을 확인합니다.
