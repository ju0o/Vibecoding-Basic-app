# AI 한방 이해하기 · 4주 집중 01강 실습

## 목표
도구 사용법을 외우기 전에, AI에게 무엇을·어디까지 맡기고 결과를 어떻게 검증·복구하는지 판단 기준을 만듭니다.

## 실행
```powershell
npm run dev:starter
npm run dev:broken
npm run dev:complete
```

기본 주소는 `http://localhost:4173`입니다. 실행 중인 서버는 `Ctrl + C`로 종료합니다.

## 세 상태
- `starter`: 수강생이 작업을 시작하는 최소 상태
- `broken`: AI 결과를 검증 없이 신뢰해 배포 후 실제 입력에서 깨짐
- `complete`: 한 문장 목표와 완료 기준, 맥락·예시 메모, 직접 실행한 검증 기록, 실패 시 복구 한 단계

## 복구
원인: 완료 기준과 검증 없이 결과 화면만 보고 진행함

첫 수정: 작은 범위로 다시 요청하고 직접 실행해 정상·실패 흐름을 확인한 뒤 진행
