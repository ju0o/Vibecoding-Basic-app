# 바이브코딩 기초반 · 2기 V3 작업본 06강 실습

## 목표
프로젝트의 문제·핵심 흐름·직접 해결한 오류를 짧게 시연하고 다음 개선 한 가지를 정합니다.

## 실행
```powershell
npm run dev:starter
npm run dev:broken
npm run dev:complete
```

기본 주소는 `http://localhost:4173`입니다. 실행 중인 서버는 `Ctrl + C`로 종료합니다.

## 세 상태
- `starter`: 수강생이 작업을 시작하는 최소 상태
- `broken`: 발표 직전 인터넷 또는 배포 URL이 열리지 않음
- `complete`: 5분 발표, 피드백 기록, 다음 개선 작업

## 복구
원인: 오프라인 대체 화면과 로컬 실행 준비가 없음

첫 수정: 로컬 완성본, 캡처, 짧은 대체 시연 순서를 준비
