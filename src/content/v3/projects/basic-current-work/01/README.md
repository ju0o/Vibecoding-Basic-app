# 바이브코딩 기초반 · 2기 V3 작업본 01강 실습

## 목표
텍스트·이미지·코딩·영상 AI가 같은 요청을 서로 다른 결과로 바꾸는 장면을 보고 도구 선택 기준을 이해합니다.

## 실행
```powershell
npm run dev:starter
npm run dev:broken
npm run dev:complete
```

기본 주소는 `http://localhost:4173`입니다. 실행 중인 서버는 `Ctrl + C`로 종료합니다.

## 세 상태
- `starter`: 수강생이 작업을 시작하는 최소 상태
- `broken`: 설명은 그럴듯하지만 실제 결과가 요구와 다름
- `complete`: AI 작업 분해표, 도구 선택 이유, 검증 질문 세 가지

## 복구
원인: 완료 기준과 검증 장면이 없음

첫 수정: 예상 결과·제약·확인 방법을 추가하고 작은 출력부터 비교
