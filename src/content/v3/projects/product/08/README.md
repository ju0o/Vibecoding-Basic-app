# AI 제품·수익화 08강 실습

## 목표
SaaS팀은 실제 출시와 지표를, 외주팀은 안전한 납품과 포트폴리오 사례를 완성합니다.

## 실행
```powershell
npm run dev:starter
npm run dev:broken
npm run dev:complete
```

기본 주소는 `http://localhost:4173`입니다. 실행 중인 서버는 `Ctrl + C`로 종료합니다.

## 세 상태
- `starter`: 수강생이 작업을 시작하는 최소 상태
- `broken`: 배포는 됐지만 아무도 다음 행동을 모름
- `complete`: 출시 URL 또는 납품 확인서, 지표·인수 문서, 팀 회고, 개인 사례 초안

## 복구
원인: 운영·측정·인수 책임이 정해지지 않음

첫 수정: 운영 Owner, 지표 대시보드, 계정 인수와 다음 실험을 명시
