# AI 제품·수익화 02강 실습

## 목표
팀과 개인 프로젝트에서 4주 안에 검증할 핵심 행동과 최소 제품 범위를 정합니다.

## 실행
```powershell
npm run dev:starter
npm run dev:broken
npm run dev:complete
```

기본 주소는 `http://localhost:4173`입니다. 실행 중인 서버는 `Ctrl + C`로 종료합니다.

## 세 상태
- `starter`: 수강생이 작업을 시작하는 최소 상태
- `broken`: 매주 기능은 늘지만 데모가 끝까지 안 됨
- `complete`: MVP 범위표, 핵심 사용자 흐름, 완료 시연 기준

## 복구
원인: 화면 단위로 만들고 사용자 흐름을 연결하지 않음

첫 수정: 핵심 행동의 시작부터 완료까지 세로 한 줄로 우선 완성
