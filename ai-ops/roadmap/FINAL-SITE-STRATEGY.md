# 최종 사이트 완성 전략 (Final Site Strategy)

Final Editorial Agent(WF-05)의 판정 기준. "강의 여러 개의 모음"이 아니라 "한 권의 교재"가 되기 위한 9개 기준과 최종 릴리스 기준을 정의한다.

## 판정 기준 9개

### 1. 강의 순서
- 어떤 강의도 뒤 강의의 개념을 전제하지 않는다 (선행 그래프 위반 0건)
- 모듈 간 이동 시 "이전 모듈에서 배운 것" 연결 문장이 각 모듈 첫 강의에 존재
- 판정 방법: 전체를 순서대로 읽으며 "이 단어를 어디서 배웠지?" 추적 (SK-05 렌즈 1의 전역 버전)

### 2. 용어 일관성
- 하나의 개념 = 하나의 표기 (glossary.ts가 표준. 본문·퀴즈·체크리스트 모두 동일 표기)
- 용어 표기 통일표를 `reports/terminology-standard.md`로 유지
- 강의 본문에 등장하는 모든 전문 용어가 용어 사전에 존재

### 3. 난이도 곡선
- 인접 강의 간 난이도 급경사 없음 (입문→기초→중급 단조 증가, 모듈 내 역행 금지)
- 각 레벨의 정의(SK-05 렌즈 2)가 전 모듈에서 동일하게 적용됨

### 4. 중복 제거
- 같은 개념의 본격 설명은 사이트에서 한 곳 (다른 곳은 요약+링크)
- 같은 비유를 두 강의에서 다른 개념에 쓰지 않음 (비유 충돌은 오개념 생성기)

### 5. 설명 방식 통일
- 13섹션 활용 패턴 동일 (예: "쉬운 비유"가 어떤 강의는 3문단, 어떤 강의는 1문장 — 편차 상한 관리)
- 경어체·코드 주석 한국어·비유 3원칙이 전 강의 적용

### 6. 출처 정리
- 깨진 링크 0건, 이전된 도메인 갱신 (분기 점검 — WF-03 노후화 점검과 통합)
- 모든 강의의 참고 출처가 SOURCE-REGISTRY 허용 출처
- 확인 날짜가 12개월 넘은 "최신성 높음" 주제(T08~T11)는 자동 개정 후보

### 7. 퀴즈 품질
- 전 문항 표면 단서 없음, 본문 근거 존재, 오답이 실제 오개념 (SK-07 전수 적용)
- 모듈 단위로 퀴즈만 연속으로 풀었을 때 난이도·형식 일관

### 8. 설명 연습 품질
- 전 문항 청자 지정, guide가 "정의→비유→예시→한계" 뼈대 제공
- 모듈 마지막 강의의 설명 연습은 모듈 전체를 종합하는 문항

### 9. 최종 릴리스 기준 (모듈 "완성" 판정)
- [ ] CURRICULUM-MAP 목표 강의 전부 released
- [ ] 위 1~8 기준의 high 이슈 0건
- [ ] 모듈 용어가 용어 사전에 전부 등재
- [ ] `npm run verify` 통과 상태
- [ ] 진행률·검색·이전/다음 이동에서 모듈 전체가 정상 동작

## 사이트 전체 "V2 완성" 선언 기준
- 13개 모듈 전부 "완성" 판정 + 전체 통독 편집 1회 완료 + 미해결 high/medium 이슈 0건

## 운영 리듬
- 강의 10개 릴리스마다: 해당 모듈 부분 검토
- 분기마다: 전체 통독 + 출처 노후화 점검
- 검토 결과는 전부 `reports/editorial-{date}.md` → REVISION-BACKLOG (직접 수정 금지)
