# 읽기 경험(UX) 디자인 브리프 — CODEX-PLAN Phase 0 입력

목적: V2 콘텐츠(8,000자+ 장문, 인용, 하이라이트, 다이어그램, 레퍼런스형)를 **깊게 읽기 좋은 그릇**에 담는다. 기존 UI는 짧은 강의+퀴즈용이었다 — 렌더링만 되는 것이 아니라 아래 기준을 충족해야 Phase 0 완료다.

## 1. 본문 타이포그래피 (장문 가독성의 뼈대)
- 본문 최대 폭: 한 줄 65~75자 (넓은 화면에서 줄이 늘어지지 않게)
- 줄 간격 1.7~1.8, 문단 간격은 줄 간격보다 뚜렷하게
- 위계: h2(8섹션) > h3(소절) > 본문 — 크기·굵기·상단 여백으로 스캔 가능하게
- 코드 블록: 배경 구분, 가로 스크롤(모바일), 언어 라벨

## 2. 인용 블록 (V2의 얼굴)
- 원어 인용 / 한국어 번역 / 출처 줄의 3층 시각 구분 (예: 원어는 기본, 번역은 옅게 또는 이탤릭, 출처는 작게 + **링크 필수**)
- 좌측 액센트 보더 + 옅은 배경 — 본문과 한눈에 구분
- 출처 링크는 새 탭, 링크 아이콘 등으로 외부 이동임을 표시

## 3. 하이라이트 (`<mark>`)
- 형광 배경: 라이트 모드 옅은 노랑 계열, 다크 모드 채도 낮춘 앰버 — 본문 대비 과하지 않게 (WCAG 대비 유지)
- 밑줄·굵기 병용 금지 (형광 하나로 충분)

## 4. 긴 페이지 내비게이션
- 사이드바 목차: 8섹션 + h3까지, **스크롤 위치 추적 하이라이트** (지금 어디를 읽는지)
- 상단 읽기 진행 바 (페이지 스크롤 %)
- 섹션 앵커 링크 (제목 호버 시 # 복사)
- "위로" 버튼 (장문 필수)

## 5. 다이어그램
- 최대 폭 제한 + 중앙 정렬 + 캡션(그림 n. 설명)
- 다크모드: SVG가 CSS 변수/currentColor를 쓰므로 배경 투명 확인

## 6. 레퍼런스형 강의 (Git 명령어 등)
- 명령어별 소절: 명령어 이름이 코드체 h3 + 앵커 — 목차에서 명령어로 바로 점프
- 소절 구조 고정: 문법 → 주요 옵션(표) → 사용 예시(코드+결과) → 주의/복구
- 페이지 상단에 명령어 인덱스 (한 줄 요약과 함께)

## 7. 상호 링크·용어
- 본문 내 용어 사전 링크는 점선 밑줄 등으로 일반 링크와 구분
- 강의 말미 "관련 강의" 블록 (KB related 기반)

## 8. 모바일·다크모드
- 표·코드·다이어그램 가로 스크롤 확인, 인용 블록 여백 축소
- 다크모드에서 하이라이트·인용 배경·SVG 전부 점검
