## Phase A — 정보구조·탐색 (최우선)

**A1. 커리큘럼 페이지 재설계**
- 모듈 아코디언(접기/펼치기, 기본: 전부 접힘 + 진행 중 모듈만 펼침) 또는 "모듈 개요 그리드 → 모듈 상세" 2단 구조 중 택1(구현 단순한 쪽).
- 각 모듈 헤더에: 강의 수, (A3 도입 시) 읽음 n/m 표시.
- 낡은 V1 문구 제거 → 현재 규모(강의 수는 데이터에서 동적 산출) 반영 카피로 교체.

**A2. 강의 검색**
- 정적 사이트이므로 클라이언트 검색: LESSON_META(제목·요약·태그) 대상 간단 필터 컴포넌트. 헤더 또는 커리큘럼 상단 배치. 외부 검색 라이브러리 없이 문자열 매칭으로 시작.

**A3. 학습 진행 추적 (localStorage)**
- 강의 페이지 하단 "읽음" 토글(또는 스크롤 90% 자동 표시) → localStorage 저장(PasswordGate와 동일 패턴, 서버 불필요).
- 커리큘럼·홈에 모듈별/전체 진행률 표시. 초기화 버튼 제공.

**A4. 이전/다음 강의 내비**
- 강의 페이지 하단에 curriculum 순서 기반 prev/next 카드(모듈 경계 표시 포함). 본문 텍스트 링크와 별개의 구조적 내비.

## Phase B — 읽기 경험 다듬기

- B1. 본문 타이포: 최대 폭(약 72ch)·행간·문단 간격 점검, 모바일 폰트 크기.
- B2. 콜아웃(4종)·하이라이트(`==`)·인용 블록의 시각 위계 정리 — 인용(원문)과 콜아웃이 한눈에 구분되게.
- B3. 코드 블록: 가로 스크롤·복사 버튼(선택).
- B4. 표: 모바일 가로 스크롤 컨테이너 확인(레퍼런스 강의는 표가 많음).
- B5. 다이어그램: 다크 모드 대비 재점검(SVG는 이미 prefers-color-scheme 지원 — 컨테이너 배경 확인).

## Phase C — 홈·용어집·마감

- C1. 홈 재구성: "이어서 읽기"(A3 연동, 마지막 읽은 강의) + 모듈 진입 그리드 + 규모 지표(강의/용어 수 동적).
- C2. 용어집: 카테고리 필터 칩 + 첫 글자 점프(선택). 용어 → 관련 강의 역링크(선택).
- C3. 리소스 페이지 문구 현행화. 전역 낡은 카피 일소.
