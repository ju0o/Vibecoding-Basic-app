## Hard gate — all required for Website “complete” and next-node COMPLETE

A node may not be marked Website-complete or advance the production board as done unless:

1. **Student Question** defined  
2. **Outcomes** evidence-linked (Observed/Assisted/Independent/Explainable)  
3. **Markdown** depth = `review_ready` (not thin outline)  
4. **Practice** executable with: start · action · expected · fail · recover · evidence  
5. **Interactive** = `interactive_learning` OR explicit `not_applicable_with_reason`  
6. **Quiz** node-specific (not batch-only) with reasons + teach-back  
7. **Sources** scoped (official / educational / blocked)  
8. **Independent Review** pass for the track unit  
9. **Relevant QA** pass (lint/typecheck/test/build as touched)  
10. **Studio status** honest (no false ◎)

## Word

- Markdown SSOT required  
- Word only if `standalone_download_worthy` or module workbook  
- Thin mechanical DOCX does **not** satisfy any gate  

## Batch speed

Batch production may continue **research→draft**, but **Website complete** and **board COMPLETE** wait for this gate.
