# Fable 사후 감사 계획 (Audit Plan)

무정지 실행(O-05.1)에서 검증 세션 분리를 포기한 대가로 도입된 대체 장치. **Codex의 Phase 5 보고 직후, 운영자 승인 전에 Fable이 수행**한다. 이후 분기마다 축소판 반복.

## 1. 감사 시점

| 시점 | 범위 |
|---|---|
| Phase 5 보고 직후 (배포 승인 전 — 필수) | 아래 전체 표본 |
| 분기 (운영 중) | 표본 절반 + 최신성 점검(WF-03과 통합) |

## 2. 표본 추출 (무작위 + 위험 가중)

| 대상 | 크기 | 가중 규칙 |
|---|---|---|
| KB 문서 | 전체의 20% (최소 5건) | Score 최하위 2건 + 재수집 루프 이력 있는 것 1건 이상 포함 |
| 강의 | 전체의 10% (최소 5강) | 유형별(심층/레퍼런스) 각 1강 이상, 기둥(A~D)별 1강 이상 |
| 용어 | 20개 | 최신 등록분 위주 |
| 다이어그램 | 5개 | 개념 관계 지도 필수 포함 |

## 3. 감사 기준 (항목별 PASS/FAIL)

1. **인용 원문 일치**: 강의·KB의 인용을 원문 URL에 **재접속해 글자 단위 대조** (무정지 실행의 자기 검증을 외부에서 재확인하는 핵심 항목)
2. **KB 역추적**: 강의 표본에서 사실 문장 10개 무작위 추출 → 근거 KB 섹션 존재 확인
3. **Score 근거 기록**: verification 기록에 원문 대조 흔적이 실재하는가 (기록 없는 PASS는 FAIL)
4. **인용 정책 준수**: [CITATION-POLICY.md](CITATION-POLICY.md) §1~3 (길이·건수·링크·해설)
5. **링크 생존**: 표본 내 출처 URL 전수 접속
6. **다이어그램 정합**: 라벨이 본문 용어와 일치, 관계 방향이 KB의 prerequisites/related와 모순 없음

## 4. 판정과 조치

- 표본 불합격률 **10% 초과** → 해당 산출물이 속한 물결 전체 재검증을 Codex에 지시 (배포 승인 보류)
- 개별 불합격 (10% 이하) → `outputs/00-backlog/REVISION-BACKLOG.md`에 등록, 배포는 진행 가능 (운영자 판단)
- 계통 오류 발견 (같은 유형 반복) → 원인 규칙을 특정해 계획서/정책 개정안 제출

## 5. 산출물

- `ai-ops/reports/audit-{date}.md`: 표본 목록, 항목별 결과 표, 불합격률, 조치, **배포 승인 권고 (APPROVE 권고 / HOLD 권고 + 사유)**
- 운영자는 이 보고서 + 개발 서버 확인으로 배포를 결정한다
