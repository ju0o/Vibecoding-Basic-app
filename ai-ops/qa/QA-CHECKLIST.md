# QA 통합 체크리스트 (작성자 자가 점검용)

Production Layer의 Agent들이 산출물 제출 전에 스스로 확인하는 요약본. 게이트의 공식 판정은 QA-GATES.md를 따른다.

## Lesson Writer 자가 점검
- [ ] 13섹션 제목 정확 (복사 원본: schema.ts)
- [ ] 브리프에 없는 사실 추가 시 [브리프 외 추가] + 출처 표시
- [ ] 새 용어 등장 즉시 한 줄 풀이
- [ ] 비유: 일상 소재 / 구조 대응 / 깨지는 지점 명시
- [ ] 코드: 실행 가능한 완결 형태, 한국어 주석, 레벨 적합
- [ ] "AI 시대에서의 의미"가 일반론이 아닌 구체 상황
- [ ] 분량 4,000~5,500자
- [ ] meta.md의 checklist가 본문에 근거를 가짐

## Quiz 자가 점검
- [ ] answer ↔ options 문자열 일치 (복사-붙여넣기로 확인)
- [ ] 오답이 실제 오개념 기반
- [ ] 정답의 근거가 본문에 존재
- [ ] explanation이 오답 이유까지 커버

## Terminology 자가 점검
- [ ] glossary.ts 전체와 대조 완료 (표기 변형 포함)
- [ ] shortDefinition 한 문장·무전문용어
- [ ] related 전부 실존 확인
- [ ] 충돌 발견 시 conflict 보고로 처리 (임의 수정 안 함)

## Research 자가 점검
- [ ] 모든 주장에 URL
- [ ] 공식 출처 60% 이상
- [ ] 버전 의존 정보에 기준 표기
- [ ] [출처 미확보] 분리 완료

## 검증 Agent 자가 점검 (Fact Check / Edu Review)
- [ ] 판정이 보고서 첫 줄에 있음
- [ ] FIX마다 구체적 수정안/방향 존재
- [ ] 자기 담당 밖 판단을 섞지 않음 (사실↔교육 분리)
