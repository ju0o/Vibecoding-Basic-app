# 인용·라이선스 정책 (Citation Policy)

운영자 방침 (2026-07-12 공개 전환): **Mode B (공개)** 가 현재 기준입니다.

## 0. 모드

| 모드 | 조건 | 인용 규칙 |
|---|---|---|
| A. 비공개 학습 (종료) | 접근 보호 + noindex | 길이 상한 없음 (과거) |
| **B. 공개 (현재)** | 검색 가능 무료 공개 | 짧은 인용(2~3문장 권장, 약 50단어 이내), **강의당 원문 인용 블록 최대 3건** |

## 1. 인용의 기본 규칙 (Mode B)

1. **길이**: 짧은 인용. 긴 원문은 축약(`[...]`)하거나 해설로 대체하고 링크만 남긴다.
2. **출처 링크 필수**: 모든 인용에 원문 URL.
3. **해설 필수**: 인용 직후 우리 해설.
4. 원문 전체 통째 번역·대량 발췌 금지.
5. 이미지·도표 복사 금지 — 자체 SVG.
6. 초과 인용은 “관련 원문(링크)” 형태로 링크만 유지할 수 있다.

## 2. 출처 유형별 취급

| 유형 | 취급 |
|---|---|
| CC 문서 (MDN 등) | 짧은 인용 + 링크 + (CC-BY-SA) 표기 권장 |
| 오픈소스 문서 | 라이선스 확인 후 짧은 인용 + 링크 |
| 벤더 공식 문서 | 짧은 인용 + 링크 + 해설 |
| 개인 블로그·미디어 | 인용 금지 |

## 3. 표기 규격

- 출처 줄: `[문서 제목 — 발행 주체](URL)`
- CC-BY-SA 시 `(CC-BY-SA)` 표기
- “더 읽기”에 원문 목록 유지

## 4. 공개 운영

- 긴 인용 스캔: `scripts/scan-citations.mjs`
- Mode B 일괄 정리: `scripts/apply-citation-mode-b.mjs`
- 리뷰 로그: `ai-ops/reports/citation-mode-b-apply-report.json`

## 5. QA

- 강의당 원문 인용 블록 ≤ 3
- 링크 없는 인용 불합격
