# 인용·라이선스 정책 (Citation Policy)

운영자 확정 방침 (2026-07-05): **짧은 인용 + 출처 링크 필수 + 해설 = 공정 이용 범위 유지.** 우려 항목은 차단하지 않고 목록화 → 유지보수 시 운영자가 직접 수정한다.

## 1. 인용의 기본 규칙 (모든 인용에 적용)

1. **짧게**: 인용 1건 = 원문 기준 2~3문장(약 50단어) 이내. 같은 문서에서 강의당 최대 3건
2. **출처 링크 필수**: 모든 인용에 원문 URL 링크 — 링크 없는 인용은 QA 불합격
3. **해설 필수**: 인용 직후 반드시 우리의 해설·분석 문단 (인용이 콘텐츠의 대체가 아니라 논증의 근거가 되게 — 이것이 변형적 이용의 핵심)
4. 원문 무수정 (생략은 `[...]` 표기), 번역은 병기하되 **문서 전체·섹션 통째 번역 금지** (부분 번역 + "전문은 원문 링크")
5. 이미지·도표 복사 금지 — 개념을 이해했으면 **자체 SVG로 재작성** (출처 문서를 "참고" 표기)

## 2. 출처 유형별 취급

| 유형 | 예 | 취급 |
|---|---|---|
| CC 라이선스 문서 | MDN (CC-BY-SA 2.5+), 일부 W3C | 표기 규격 준수 시 인용 여유 있음 — 단 본 정책의 "짧게" 규칙을 기본 유지, 출처·라이선스 표기 |
| 오픈소스 문서 | MCP 문서(오픈소스 저장소), 오픈소스 도구 README | 라이선스(MIT 등) 확인 후 인용 — 표기 규격 준수 |
| 일반 저작권 | Anthropic·OpenAI 블로그/문서, 벤더 공식 문서 대부분 | **§1 규칙 엄수** (짧은 인용+링크+해설만). 대량 발췌·통째 번역 금지 |
| 공식 예제 코드 | 문서 내 코드 스니펫 | 짧은 스니펫은 출처 표기로 인용 가능하나, **가급적 자체 작성 예시 우선** |
| 개인 블로그·미디어 | — | 인용 금지 (기존 SOURCE-REGISTRY 규칙과 동일) |

## 3. 표기 규격

- 인용 블록 출처 줄: `[문서 제목 — 발행 주체](URL)` (CONTENT-FORMAT-V2 §2 형식)
- CC-BY-SA 출처(MDN 등) 인용 시 출처 줄에 라이선스 표기 추가: `(CC-BY-SA)`
- 강의 "더 읽기" 섹션에 그 강의가 인용한 모든 원문 목록

## 4. 우려 항목 처리 (비차단 — 운영자 방침)

- 작성 중 "이 인용이 §1~2 기준에 애매하다" 싶으면 **작업을 멈추지 말고** `ai-ops/reports/citation-review.md`에 한 줄 기록: `| 강의 slug | 인용 출처 | 우려 사유 |`
- 이 목록은 Phase 5 보고에 첨부 → **운영자가 유지보수에서 직접 수정** (삭제·축약·재작성 판단은 운영자)
- 외부에서 삭제 요청이 오는 경우도 같은 경로: 목록에 기록 → 운영자 수정
