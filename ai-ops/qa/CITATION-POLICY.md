# 인용·라이선스 정책 (Citation Policy)

|---|---|---|
| **A. 비공개 학습 (현재)** | 배포하되 **접근 보호 + noindex** (아래 §0-1) — 운영자 혼자 외부 접속용 | 길이 상한 없음 — 이해에 필요한 만큼 인용 가능. 단 §1의 2·3·4·5는 유지 |
| **B. 공개 (추후)** | 운영자가 "공개 전환"을 선언하고 §4의 정리를 마친 뒤 | 짧은 인용(2~3문장, 문서당 3건) 기준으로 복귀 |

### 0-1. 모드 A의 기술 조건 (배포 시 필수 — 이것이 "사적 이용"의 근거)
- 검색 차단: `robots.txt` 전체 차단 + 전 페이지 `noindex` 메타
- 접근 보호: 간단한 접근 제한 (Next.js 미들웨어 Basic Auth(환경변수 비밀번호) 또는 Vercel 배포 보호 — 구현이 간단한 쪽)
- 이 두 가지 없이 모드 A 인용 규칙으로 배포 금지

## 1. 인용의 기본 규칙

1. **길이**: 모드 A에서는 상한 없음 / 모드 B에서는 2~3문장(약 50단어), 문서당 강의당 3건
2. **출처 링크 필수** (모드 무관): 모든 인용에 원문 URL — 링크 없는 인용은 QA 불합격
3. **해설 필수** (모드 무관): 인용 직후 우리의 해설·분석 문단 — 학습 품질의 핵심이기도 함
4. 원문 무수정 (생략 `[...]`), 문서 **전체** 통째 번역은 모드 A에서도 지양 (섹션 단위까지 허용) — 나중에 정리 비용이 커짐
5. 이미지·도표 복사 금지 (모드 무관) — 자체 SVG 재작성 (다크모드·일관성 때문이기도 함)
6. **긴 인용 자동 기록** (모드 A의 핵심 장치): 모드 B 기준(2~3문장)을 초과하는 모든 인용은 작성 시점에 `ai-ops/reports/citation-review.md`에 자동 기록 — `| 강의 slug | 출처 | 인용 길이 | 섹션 위치 |`. **이 목록이 곧 공개 전 정리 작업 목록이 된다** (공개 시점에 뒤져서 찾는 일이 없게)

## 2. 출처 유형별 취급

| 유형 | 예 | 취급 |
|---|---|---|
| CC 라이선스 문서 | MDN (CC-BY-SA 2.5+), 일부 W3C | 표기 규격 준수 시 인용 여유 있음 — 단 본 정책의 "짧게" 규칙을 기본 유지, 출처·라이선스 표기 |
| 오픈소스 문서 | MCP 문서(오픈소스 저장소), 오픈소스 도구 README | 라이선스(MIT 등) 확인 후 인용 — 표기 규격 준수 |
| 일반 저작권 | Anthropic·OpenAI 블로그/문서, 벤더 공식 문서 대부분 | **§1 규칙 엄수** (짧은 인용+링크+해설만). 대량 발췌·통째 번역 금지 |
| 공식 예제 코드 | 문서 내 코드 스니펫 | 짧은 스니펫은 출처 표기로 인용 가능하나, **가급적 자체 작성 예시 우선** |
| 개인 블로그·미디어 | — | 인용 금지 (기존 SOURCE-REGISTRY 규칙과 동일) |

## 3. 표기 규격

- 인용 블록 출처 줄: `[문서 제목 — 발행 주체](URL)` (CONTENT-FORMAT-V2 §2 형식)
- CC-BY-SA 출처(MDN 등) 인용 시 출처 줄에 라이선스 표기 추가: `(CC-BY-SA)`
- 강의 "더 읽기" 섹션에 그 강의가 인용한 모든 원문 목록

## 4. 공개 전환 절차 (모드 A → B, 운영자 주도)

1. 운영자가 "공개 전환" 선언
2. `reports/citation-review.md`의 긴 인용 목록을 전수 처리 — 축약·해설로 대체·삭제는 **운영자가 직접 수정** (운영자 방침: "유지보수 때 내가 직접 수정하면 상관없다")
3. 처리 완료 후 §0-1의 접근 보호 해제 (noindex 제거는 마지막)
- 외부 삭제 요청이 오는 경우도 같은 경로: 목록에 기록 → 운영자 수정
