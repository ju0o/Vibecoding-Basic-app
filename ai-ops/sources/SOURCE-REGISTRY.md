# 출처 등록부 (Source Registry)

Research·Fact Check Agent가 사용하는 허용 출처 목록. 새 출처는 Research Agent가 제안하고 운영자가 승인해 이 표에 추가한다.

| 분야 | 출처 | URL |
|---|---|---|
| 웹 표준 | MDN Web Docs | https://developer.mozilla.org |
| TypeScript | TypeScript Docs | https://www.typescriptlang.org/docs |
| React | React 공식 문서 | https://react.dev |
| Next.js | Next.js Docs | https://nextjs.org/docs |

## 3순위 — 공식 블로그·릴리스 노트 (역사·버전 정보용)
- Anthropic News (https://www.anthropic.com/news)
- OpenAI Blog, React Blog, Next.js Blog, GitHub Blog
- 각 도구의 GitHub Releases / CHANGELOG

## 사용 규칙
- 개인 블로그·번역 요약글: 사실의 유일한 근거로 사용 금지 (비유·설명 아이디어 참고만 가능, 브리프에 인용하지 않음)
- 위키백과: 출발점으로만. 인용은 위키가 참조한 원출처로
- AI 생성 요약(검색 AI 답변 포함): 출처로 사용 금지
- 확인 날짜를 항상 기록 — 문서는 바뀐다

## 신규 출처 제안 형식
`| 분야 | 이름 | URL | 제안 사유 | 제안 Agent | 승인 여부 |` 를 이 파일 하단 "제안 대기" 섹션에 추가.
