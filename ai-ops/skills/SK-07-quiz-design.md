# SK-07 Quiz Design (퀴즈 설계)

Quiz Agent의 설계 규칙.

## 좋은 문항의 조건
1. **오개념 기반 오답**: 오답 2개는 학습자가 실제로 착각하는 지점이어야 한다. 재료는 브리프의 "자주 혼동되는 개념"과 강의의 "자주 헷갈리는 것" 섹션.
2. **본문 근거**: 정답의 근거가 강의 본문에 명시적으로 존재해야 한다. 본문에 없는 지식을 요구하면 FIX.
3. **표면 단서 제거**: 정답이 가장 길거나, 가장 그럴듯한 어휘를 쓰거나, "항상/절대"가 오답에만 있는 패턴 금지.
4. **암기 아닌 판별**: "X의 정의는?"보다 "다음 상황에서 X에 해당하는 것은?"이 낫다.

## explanation 작성 규칙
- 1문장: 왜 정답인가 (본문 근거)
- 1~2문장: 각 오답이 왜 틀렸는가 (어떤 착각에서 나오는가)

## 설명 연습(explanationPrompt) 설계
- prompt: 구체적 청자를 지정한다 — "비개발자 동료에게", "이 개념을 처음 듣는 친구에게"
- guide: 설명에 반드시 포함될 포인트 3~4개. 체크리스트를 복사하지 말고, "설명의 뼈대" 관점으로 다시 쓴다 (정의 → 비유 → 예시 → 한계 순 권장)

## 규격 (schema.ts LessonExercise)
- options는 정확히 3개 (기존 강의 관례), answer는 options 중 하나와 문자열 완전 일치
