# SK-01 Official Documentation Research (공식 문서 리서치)

재사용 가능한 리서치 절차. Research Agent가 주로 쓰고, Fact Check Agent가 검증 시 재사용한다.

## 절차

1. **출처 우선순위 적용** (`sources/SOURCE-REGISTRY.md` 기준):
   - 1순위: 벤더 공식 문서 (MDN, react.dev, nextjs.org, docs.anthropic.com, platform.openai.com, modelcontextprotocol.io 등)
   - 2순위: 표준 기구 (W3C, WHATWG, IETF, OWASP)
   - 3순위: 공식 블로그·릴리스 노트 (버전·역사 정보용)
   - 사용 금지: 개인 블로그·번역 요약글을 사실의 유일한 근거로 쓰는 것 (참고 영감용으로만)
2. **개념 4분해**: 정의 → 등장 배경(무엇이 불편해서 생겼나) → 동작 방식 → 실무 사용법. 각 조각마다 출처를 붙인다.
3. **버전 고정**: 버전 의존 정보는 "기준: {도구} v{X}, {YYYY-MM} 확인"을 반드시 표기.
4. **인용 규격**: `주장 문장 — [문서 제목](URL) ({확인 날짜})`
5. **모르면 모른다고 기록**: 출처를 못 찾은 항목은 브리프에 `[출처 미확보]` 섹션으로 분리한다. 지어내서 채우는 것이 최악의 실패다.

## 산출 형식
브리프 규격은 research-agent.md의 출력 정의를 따른다.

## 실패 패턴 (피해야 할 것)
- 검색 결과 요약본(블로그)을 원문 확인 없이 인용
- 최신 문서 대신 학습 데이터 기억으로 작성 — 반드시 오늘 문서를 열어 확인
- 대상 레벨 무시하고 심화 자료만 수집
