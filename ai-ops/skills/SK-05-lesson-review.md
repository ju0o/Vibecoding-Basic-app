# SK-05 Lesson Review (강의 리뷰)

Education Review Agent의 검토 렌즈. QA Agent도 일부 항목을 재사용한다.

## 검토 렌즈 5개 (순서대로 적용)

### 1. 선행 지식 렌즈
초안을 읽으며 "이 단어/개념을 독자가 어디서 배웠지?"를 모든 전문 용어에 묻는다.
- 선행 강의에 있음 → OK
- 이 강의에서 즉시 풀이됨 → OK
- 둘 다 아님 → 위반. 풀이 추가 또는 선행 강의 지정 요구

### 2. 난이도 렌즈
- 입문: 코드보다 개념 중심, 비유 필수, 결과 화면 제시
- 기초: 코드를 따라 칠 수 있음, 용어 풀이 유지
- 중급: 트레이드오프·설계 판단 포함 가능
- 레벨 표기와 본문 난이도가 어긋나면 FIX

### 3. 비유 렌즈
비유의 요소를 개념의 요소와 1:1 대응표로 그려본다. 대응이 안 되는 요소가 절반 이상이면 비유 교체 요구. 비유가 오개념을 만들 수 있는 지점은 반드시 지적.

### 4. 설명 가능성 렌즈
"이 강의만 읽은 사람이 체크리스트 항목을 실제로 말할 수 있나?"를 항목별로 시뮬레이션. 본문에 근거가 없는 체크리스트 항목은 FIX.

### 5. 흐름 렌즈
13섹션이 서로 모순되지 않는지 (한 줄 정의 ↔ 핵심 개념 ↔ 헷갈리는 것), 같은 내용이 두 섹션에서 반복되지 않는지.

## 보고 규칙
- 섹션별로 코멘트 또는 "이상 없음"
- FIX마다: 위치 + 왜 학습을 방해하는가 + 수정 방향 (직접 고치지 않는다 — 수정은 Writer의 일)
