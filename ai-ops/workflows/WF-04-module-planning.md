# WF-04 모듈 기획 Workflow (모듈 → 강의 목록)

새 모듈을 강의 backlog로 분해할 때 사용. 강의 300개 체제의 출발점.

```
[모듈 목표 확인] → [주제 지도 작성] → [강의 분해] → [선행 관계 그래프] → [backlog 등록]
```

## 절차

1. **모듈 목표 확인** — Curriculum Agent가 `curriculum.ts`의 모듈 goal을 기준으로 "이 모듈을 마친 사람이 설명할 수 있어야 하는 것" 목록을 만든다.
2. **주제 지도 작성** — Research Agent가 해당 분야의 공식 문서 목차·업계 표준 커리큘럼을 조사해 주제 후보를 수집한다. 출력: `outputs/01-briefs/module-{id}-topic-map.md`
3. **강의 분해** — Curriculum Agent가 주제를 강의 단위로 자른다. 규칙:
   - 강의 1개 = 35~50분 분량 = "한 번에 설명 가능한 개념 덩어리 1개"
   - 13섹션 형식으로 쓸 수 없는 주제(순수 실습 등)는 project-textbook 모듈로 보낸다
4. **선행 관계 그래프** — 각 강의에 선행 강의를 지정. 순환 참조가 나오면 분해를 다시 한다.
5. **backlog 등록** — BACKLOG.md에 일괄 추가, 운영자 승인.

## 품질 기준
- 모듈당 강의 8~25개 (넘으면 모듈 분할 제안)
- 모든 강의가 모듈 goal 중 최소 1개에 기여함을 명시
- 레벨 곡선이 모듈 내에서 역행하지 않음
