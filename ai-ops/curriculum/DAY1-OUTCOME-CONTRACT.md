## 1. Mission

Students get a **small success first**, then learn **why** tools appeared.

Core message:

> AI에게 요청해서 결과물을 만들 수 있다.  
> 그리고 그 결과가 어떻게 실행됐는지 조금씩 이해하기 시작한다.

---

## 2. Paths (not competitors)

| Path | Goal | Time |
|---|---|---|
| **A — Zero-Setup Quick Win** | First success without local toolchain | ~10 minutes target |
| **B — Local Setup** | Computer ready for later lessons | **Not** guaranteed 10 min |

Complete Day 1 = Path A success **and** Path B minimum verification (or documented deferral with return plan — see Assessment).

---

## 3. Required outcomes (can-do)

| ID | Outcome | Min level for Complete | Target level |
|---|---|---|---|
| O1 | Explain vibe coding vs traditional coding in own words | Assisted | Explainable |
| O2 | Ask AI for a small deliverable | Independent | Independent |
| O3 | Request ≥1 revision after seeing result | Independent | Independent |
| O4 | Explain IDE as place to edit code/projects | Assisted | Explainable |
| O5 | Check whether VS Code is installed | Independent | Independent |
| O6 | Check whether Node.js is installed | Independent | Independent |
| O7 | Open a terminal | Independent | Independent |
| O8 | Run `node -v` and `npm -v` | Independent | Independent |
| O9 | Open a provided/local project folder | Assisted | Independent |
| O10 | Start a dev server following guide | Assisted | Independent |
| O11 | Confirm result in a browser | Independent | Independent |
| O12 | Explain package.json, src, npm install, npm run dev at basic level | Assisted | Explainable |
| O13 | Copy an error message and paste it to AI | Independent | Independent |

### Levels

| Level | Meaning |
|---|---|
| Observed | Followed along while watching |
| Assisted | Can do with checklist/hints |
| Independent | Can redo without step-by-step |
| Explainable | Can teach the *why* to someone else |

### Minimum Complete (Day 1)

- Path A: O2, O3, O11 (via browser) at **Independent**
- Path B: O5–O8 at **Assisted** or better; O9–O10 **Assisted** if environment allows
- O1, O4, O12 at **Assisted** (teach-back or checklist)
- O13 at **Assisted** (may be simulated if no real error)

### Recommended Complete

- All required IDs at Independent+
- O1, O4, O12 at Explainable
- Real Path B project run (O9–O11 on local server)

If Path B is blocked (admin rights, shared PC): student may earn **Partial Complete — Path A** and schedule Path B lab; full course progress flags Path B incomplete.
