## 이 수업의 자리

Day1·파일 구조·Node/npm으로 **실행**은 해봤습니다.  
오늘은 도구와 말(모델)의 **자리**를 정리합니다. 제품 가격·순위는 다루지 않습니다.

## 질문

- AI와 LLM은 같은가?  
- IDE와 VS Code는 같은가?  
- AI IDE는 일반 IDE와 뭐가 다른가?  
- AI는 파일을 어떻게 “만들고 수정”하나?

## 구분 (교육용 · 과장 금지)

| 말 | 기초 설명 |
|---|---|
| **AI** | 넓은 말. 규칙·통계·학습 기반 시스템 등 여러 기술을 포함 |
| **LLM** | 텍스트를 다루는 **대형 언어 모델** 계열. 채팅·코드 초안 등에 쓰임 |
| **IDE** | 코드 편집·탐색·터미널 등을 묶은 **작업 공간** 개념 |
| **VS Code** | 널리 쓰이는 **편집기/IDE 제품** 예시 (유일한 IDE 아님) |
| **AI IDE / AI 코딩 도구** | 편집 공간 + **대화·에이전트로 생성·수정**을 돕는 제품/확장 |

**AI ≠ 항상 LLM.** LLM은 AI의 한 종류에 가깝게 이해하면 초보 단계에 충분합니다.  
**생성 ≠ 자동 저장/실행.** 모델이 텍스트를 제안하고, 도구·사람·환경이 파일에 쓰고 실행합니다. (교육 해석 · 마법 표현 금지)
