## 실습 1 — 파일 역할 찾기

찾기:

- [ ] 프로젝트 루트 (`package.json` 위치)
- [ ] package.json
- [ ] src 폴더
- [ ] 브라우저 문구 파일 (`src/main.js`)
- [ ] 실행 방법 안내 (`README.md` 또는 package.json scripts)

## 실습 2 — 파일 하나만 수정

3. 브라우저 확인 (서버 실행 중이면 새로고침)  
4. 변경 전후 한 줄 메모
