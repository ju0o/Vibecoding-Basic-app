# 실습 — Node · npm · package.json

sample: `examples/day1-first-success` (재사용)

1. package.json에서 name, scripts.dev, (있으면) deps 찾기 · 실행 파일 `server.js` 확인  
2. scripts → `npm run dev` → `node server.js` → 브라우저 연결  
3. `npm run serve` (의도적 실패) → scripts 확인 → 올바른 명령  
4. 잘못된 폴더 상황 가정 → 루트로 이동
