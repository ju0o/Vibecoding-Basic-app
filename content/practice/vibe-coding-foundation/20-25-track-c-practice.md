# Guided Practice — C05–C10

## 공통 규칙

설명만 읽기·한 줄 감상만 = 미완료.  
각 행의 **행동·증거** 필수.

## C05 작업 분해

| 시작 | 메모 앱 같은 큰 목표 문장 |
| 행동 | 3단계 이하 + 성공 기준 각 1줄 + “나중 일” 1개 |
| 기대 | 검증 가능한 조각 |
| 실패 | 6단계+ 또는 기준 없음 |
| 복구 | 이번 주 확인 가능한 것만 |
| 증거 | 목록 사진/메모 |

## C06 Fix Loop

| 시작 | 오류 1건 (실습 또는 시뮬) |
| 행동 | 재현→증거→가설1→수정→재실행 기록 |
| 기대 | 5칸 채움 |
| 실패 | 증거 없이 재생성 |
| 복구 | A06 패킷 템플릿 |
| 증거 | 5칸 워크시트 |

## C07 QA

| 시작 | AI 초안 1건 |
| 행동 | 범위·비밀·실행·의도 4체크 |
| 기대 | 미통과 시 C06 복귀 |
| 실패 | “된 것 같음”만 |
| 복구 | 체크리스트 강제 |
| 증거 | 체크 기록 |

## C08 Agent

| 시작 | 작은 목표 1개 |
| 행동 | 허용 도구/금지 파일 + Agent 한 줄 정의(브랜드 없이) |
| 기대 | 권한 의식 |
| 실패 | 제품명=정의 |
| 복구 | 본문 오개념 표 |
| 증거 | 정의+금지 목록 |

## C09 SubAgent

| 시작 | 같은 목표 |
| 행동 | 조사/작성/검토 표 + 요청문 3개 |
| 기대 | 역할 분리 |
| 실패 | 역할 중복 |
| 복구 | 금지 열 채우기 |
| 증거 | 표 |

## C10 Workflow

| 시작 | Track C 템플릿 |
| 행동 | 5–7단계 재작성 + HITL 표시 |
| 기대 | 사람 확인 지점 ≥1 |
| 실패 | 자동화만 나열 |
| 복구 | QA 단계 삽입 |
| 증거 | 워크플로 메모 |
