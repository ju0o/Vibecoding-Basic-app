# Assessment — project-file-structure

## Quiz (개념)

1. `src`는 모든 프로젝트에 필수인가? → **아니오 (관례)**  
2. package.json 역할에 **가장 가까운 것**? → 메타데이터·scripts·(있으면)의존성  
3. 문구 바꾸기 전 먼저? → 어느 파일이 담당인지 찾기/분석  
4. AI 요청 시? → 파일 범위 제한  
5. 단일 HTML vs 분리 구조? → 상황에 따라 (무조건 우열 없음)

## Teach-back

“파일이 많아도 당황하지 않고 수정 위치를 찾는 방법”을 자기 말로.

## Complete

Quiz + 실습 1·2 수행 증거 (파일 찾기·수정). Quiz만으로 완료 아님.
