## 중복 방지 기준

- Workflow 과정은 제품별 명령어와 설정 파일을 작성하지 않는다.
- Claude와 Codex 과정은 Workflow 이론을 다시 강의하지 않고 같은 원리를 제품에서 구현한다.
- Claude와 Codex는 순차 필수 과정이 아니다. 수강생의 주 도구에 따라 하나를 선택한다.
- 제품·수익화 과정은 Agent 도구 기능이 아니라 고객, 협업, 출시와 납품을 평가한다.
