# V3 Beta QA 체크리스트

## 현재 운영본 보호

- [ ] `npm run audit:curriculum`에서 V2 동결 파일 해시 통과
- [ ] 학생 모드에서 기초반 2기 6주가 기본 선택
- [ ] 기존 1~6강 실행과 진행 상태 확인

## 화면

- [ ] 1280×720에서 세 개 패널이 겹치지 않음
- [ ] 1920×1080에서 글자와 버튼이 과도하게 작아지지 않음
- [ ] 학생 모드는 5개 과정만 표시
- [ ] 강사 모드는 다음 기수 4주 개편본 표시
- [ ] `Ctrl+K` 과정·회차·자료 검색

## 강의 엔진

- [ ] 28개 회차 각각 13장
- [ ] 시작·다음·일시정지·초기화 수동 제어
- [ ] 30분 또는 40분 실습 타이머
- [ ] 정상·실패 비교와 오류 복구 장면

## 자료

- [ ] 과정 안에서 수강생 5종, 강사 5종 표시
- [ ] 어두운 강의 CSS와 밝은 A4 인쇄 CSS 분리
- [ ] PDF 페이지 수와 설계 시트 수 일치
- [ ] 자간, 대비, 표와 체크박스 확인
