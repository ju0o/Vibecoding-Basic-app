# V3 Beta QA 체크리스트

## 현재 운영본과 작업본

- [ ] `npm run audit:curriculum`에서 V2 동결 파일 해시 통과
- [ ] 학생 모드에서 기초반 2기 6주가 기본 선택
- [ ] 기존 1~6강 실행과 진행 상태 확인
- [ ] 강사 모드에서 각 회차의 현재 운영본·V3 작업본 선택
- [ ] 검수한 작업본만 운영본으로 승격되고 이전 버전 복구 가능

## 화면

- [ ] 1280×720에서 세 개 패널이 겹치지 않음
- [ ] 1920×1080에서 글자와 버튼이 과도하게 작아지지 않음
- [ ] 1366×768에서 세 개 패널과 상세 화면이 겹치지 않음
- [ ] 학생 모드는 5개 과정만 표시
- [ ] 강사 모드는 다음 기수 4주 개편본 표시
- [ ] `Ctrl+K` 과정·회차·자료 검색

## 강의 엔진

- [ ] 현재 작업본 포함 34개 회차 각각 13장
- [ ] 시작·이전·다음·일시정지·초기화 수동 제어
- [ ] 34개 고유 scene id와 회차별 대표 장면
- [ ] 슬라이드 이탈 시 장면과 타이머 정지
- [ ] 30분 또는 40분 실습 타이머
- [ ] 정상·실패 비교와 오류 복구 장면

## 자료

- [ ] 신규 과정 수강생 6종, 강사 7종 표시
- [ ] 34개 starter·broken·complete 실습 패키지 실행
- [ ] 34개 오프라인 대체 PNG 표시
- [ ] 13장별 SAY·DO·ASK·예상 답변·복구 대본
- [ ] 어두운 강의 CSS와 밝은 A4 인쇄 CSS 분리
- [ ] 65개 PDF의 페이지 수와 설계 시트 수 일치
- [ ] 자간, 대비, 표와 체크박스 확인
