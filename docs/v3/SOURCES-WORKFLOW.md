# 공식 참고자료 갱신

## 실행

```bash
npm run sources:refresh
```

스크립트는 허용된 공식 도메인만 방문하며 다음 정보를 갱신한다.

- 공식 URL과 최종 이동 URL
- 확인 날짜
- HTTP 응답 상태
- 페이지 제목
- 기능 안정성
- 쉬운 한국어 설명
- 강사가 알아야 할 주의점

## 수업 전 확인

설치 명령, 운영체제 지원, 가격·요금제, 사용 한도, 베타·실험 기능은 변할 수 있으므로 기수 시작 전과 해당 수업 당일 다시 확인한다.

공식 문서 원문 전체는 저장하지 않는다. 링크와 강의용 한국어 요약만 관리한다.
