# VIBE STUDIO V3 커리큘럼

## 운영 원칙

- 현재 `기초반 2기 6주 활성 운영본`은 해시로 보호한다.
- V3 작업본은 별도로 제작하고 스크린샷·현장 QA를 통과한 회차만 운영본으로 승격한다.
- V3 앱은 단일 강사용 로컬 스튜디오로 운영한다.
- 수강생에게 줄 자료는 `수강생 출력물`에서 인쇄·PDF로 관리한다.
- 다음 기수 4주 개편본은 같은 스튜디오 안에서 준비·검수한다.
- V3의 모든 신규 회차는 120분이며 `진단 10 → 이론·시각화 35 → 시연 20 → 실습 40 → 복구·리뷰 15`로 운영한다.
- 모든 회차는 고유 장면, 수동 제어, starter·broken·complete 실습 파일과 오프라인 대체 캡처를 갖는다.
- Claude Code와 Codex 전문과정은 회차마다 공식자료 연구노트 3개 이상을 연결한다.
