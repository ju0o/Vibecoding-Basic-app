# 4강 및 강의 프로그램 최종 점검

점검일: 2026-06-15

## 4강 반영 내용

- 4번과 6번 시연은 슬라이드 진입 시 자동 재생하지 않는다.
- 강사가 `시연 시작`을 눌렀을 때만 가상 커서가 천천히 움직인다.
- 4번은 `app → page.tsx → Button.tsx`를 찾는 목적을 분명히 보여준다.
- 5번은 `src/` 안을 페이지, 공용 부품, 처리, 스타일의 네 작업 구역으로 나눈다.
- 7번은 package.json, package-lock.json, node_modules, README, .gitignore마다 서로 다른 시각 자료가 표시된다.
- 8번은 페이지 뼈대, 공용 부품, 스타일, 데이터가 브라우저 화면으로 조립되는 순서를 수동으로 확인한다.
- 9번은 페이지 파일, 공용 컴포넌트, 전역 스타일을 바꿀 때 달라지는 화면 범위를 비교한다.
- 11번은 설명 카드가 아닌 4문제 수정 안전도 퀴즈로 정리했다.
- 네트워크 투표가 필요했던 실시간 퀴즈는 제거하고 15번을 수업 요약 장면으로 교체했다.
- 16번은 큰 30분 타이머와 실습 안내만 남겼다.
- 17번은 5강의 배포, 비밀값, 데이터, 공개 전 점검을 예고한다.

## 무선 리모컨 제거

모바일 리모컨은 같은 네트워크, 방화벽, IP와 포트 설정에 따라 현장에서 연결 상태가 달라질 수 있다. 현재 수업 운영에 비해 복잡도가 높아 프로그램에서 완전히 제거했다.

- 로컬 HTTP 서버와 원격 제어 API 제거
- QR 모달과 리모컨 버튼 제거
- 원격 퀴즈 페이지와 투표 API 제거
- 관련 preload IPC와 사용하지 않는 스타일 제거

강의 프로그램은 인터넷 연결 없이도 강의 선택, 자료 열람, 발표자 메모, 판서, 전체화면, 인쇄와 PDF 저장을 사용할 수 있다.

## 프로그램 V2 구조

- 과정이 늘어날 수 있도록 `기초반`, `응용·수익화반`, `AI 워크스페이스 심화반`을 분리했다.
- 과정별 목표, 단계, 회차 수와 상태를 대시보드에서 확인한다.
- 자료실을 `수강생 자료`와 `강사 자료실`로 분리했다.
- 강사 자료실에 후속 과정 설계와 강사 학습 로드맵을 추가했다.
- Electron 팝업 권한을 제거하고 렌더러 보안 정책을 추가했다.
