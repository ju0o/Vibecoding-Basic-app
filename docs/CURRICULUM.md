
# 바이브코딩 기초반 커리큘럼

## 1회차. AI 이해하기
- 이론 30분: AI 종류, AI로 무엇을 할 수 있는가, AI를 도구로 바라보는 관점
- 별첨자료: 1~6강 커리큘럼 1페이지 요약, AI 종류별 특화 도구 가이드, 2회차 사전 준비자료
- 숙제: Node.js LTS, VS Code, Cursor/Kiro/Antigravity/Windsurf 중 하나 설치 후 Windows/Mac 환경에 맞게 확인 명령어 실행

## 2회차. 바이브코딩
- 이론 30분: 바이브코딩이란 무엇인가, 바이브코딩 툴 종류, 코딩 툴 연동 방법
- 실습 30~50분: HTML 또는 간단한 웹페이지 실행/수정
- 별첨자료: 명령어 치트시트, AI 작업지시서 템플릿, MVP 기획 워크시트, 수강생 실습 기록지

## 3회차. 개발 용어 이해
- 이론 30분: 프론트엔드, UI/UX, 화면 애니메이션, 백엔드, 데이터베이스, API가 연결되는 흐름
- 실습 30분: 각자 만들고 싶은 프로젝트를 자유롭게 진행
- 강의 마무리: 마지막 두 장은 실습 30분 타이머와 4강 파일 구조 예고로 고정
- 인터랙션 원칙: 표지·건축 과정·백엔드 흐름은 강사가 한 단계씩 멈춰 설명하는 수동 진행을 우선
- 디자인 테마: 실제 건축 시각화와 식당 단면, 따뜻한 흑연색 배경, 절제된 청록 포인트
- 시그니처 장면: 빈 땅 → 3D 설계도 → 철골 → 외관 → 비어 있는 내부 → 조명·수도·공간을 채우는 내부 공사 → 준공과 배포
- 별첨자료: 3강 수강생 한 장 요약, UI/UX·프론트엔드·애니메이션 예시집, 한 기능 완성 점검 워크시트, 시각적 데이터 흐름, AI 작업지시서 템플릿
- 강사용 자료: 3강 슬라이드별 대본, 3강 강사용 공부자료

## 4회차. 파일 구조 이해
- 이론 20분: 프로젝트 루트, src, app/pages, components, lib, public, package.json, package-lock.json, node_modules, README.md, .gitignore의 역할
- 실습 40분: 브라우저에서 수정할 장면을 정하고 VS Code 파일 검색 → 관련 파일 역할 확인 → 작은 수정 → 브라우저 검증
- 연결 흐름: 3강에서 배운 화면과 기능이 실제 프로젝트의 어느 페이지·부품·스타일 파일에 들어 있는지 추적하기
- 핵심 시연: 파일 트리에서 page.tsx, Button.tsx, globals.css를 선택하면 코드와 브라우저의 연결 영역이 함께 강조되고 문구·색상·간격이 실제로 변경됨
- 고도화 시연: 페이지 파일·공용 컴포넌트·전역 스타일을 바꿀 때 변화가 퍼지는 범위를 비교하고, AI가 만든 diff에서 변경 파일·삭제 줄·새 패키지를 검토
- AI 협업 원칙: 바로 수정시키지 않고 `찾기 → 설명 → 영향 확인 → 수정 → diff 검토 → 브라우저 검증` 순서로 요청
- 디자인 테마: 흑연색 개발 워크스페이스, 아이보리 문서, 절제된 코랄 포인트를 사용한 프로젝트 관제실
- 별첨자료: 4강 수강생 파일 지도 및 파일 추적 워크시트, 프로젝트 폴더 구조 설명, 명령어 치트시트, 에러 해결 가이드, 수강생 실습 기록지
- 강사용 자료: 4강 20장 상세 대본, 파일 구조와 파일 형식 강사용 공부자료

## 5회차. 배포와 보안 그리고 데이터 이해
- 이론 25분: 배포, 환경변수, API 키, 데이터베이스, 배포 전 체크리스트
- 실습 35분: 내 프로젝트 배포 준비, 환경변수/데이터 구조 점검
- 연결 흐름: 4강에서 찾은 파일을 저장소, 배포 서비스, 공개 URL과 연결하고 비밀값을 보호하기
- 별첨자료: 5강 서비스 공개 점검표, 데이터베이스 완전 가이드, 배포 전 체크리스트, 시각적 다이어그램, 에러 해결 가이드
- 강사용 자료: 5강 슬라이드별 대본, 5강 강사용 공부자료

## 6회차. 발표 및 서로 피드백
- 각자 만든 프로그램 발표
- Q&A 및 다음 고도화 방향 정리
- 연결 흐름: 완성한 서비스를 준공 발표처럼 시연하고 다음 버전의 공사 목록을 정리하기
- 별첨자료: 6강 쇼케이스 발표지, 발표 템플릿, 수강생 실습 기록지
- 강사용 자료: 6강 슬라이드별 대본, 6강 강사용 공부자료

## 프린트용 별첨자료 운영 방식
- 수강생에게 실제로 나눠줄 자료만 앱의 별첨자료 대시보드에 노출합니다.
- 설치 자료는 링크보다 검색어와 공식 다운로드 위치, 확인 명령어 중심으로 안내합니다.
- 실습 시간에는 `명령어 치트시트`, `AI 작업지시서 템플릿`, `에러 해결 가이드`, `수강생 실습 기록지`를 책상 위에 두고 반복 사용합니다.
- 사용 회차, 사용 방식, 배포 안내는 각 별첨자료 우측 하단의 `강사용 안내` 버튼으로만 확인합니다.
- `강사용 안내`는 화면에서만 보이며 인쇄/PDF 저장 시 출력되지 않습니다.
- 중복되거나 기초반에서 바로 쓰지 않을 자료는 삭제하지 않고 디자인 레퍼런스용으로만 보존합니다.

## 응용반으로 이동할 주제
- 프로젝트 방향성 정하기, 포트폴리오, SaaS, 외주, 수익화는 기초반 이후의 응용 과정에서 다룹니다.
- 기초반의 핵심 목표는 6주 동안 작은 프로젝트를 직접 만들며 바이브코딩 흐름을 손에 익히는 것입니다.
